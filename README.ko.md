# Classic Pattern Explorer 3.1

[English](README.md) | [한국어](README.ko.md) | [日本語](README.ja.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [Tiếng Việt](README.vi.md)

Classic Pattern Explorer는 한문(漢文, Literary Sinitic) 원문에서 以…爲, 雖…而 같은 문형의 후보를 찾아 주는 데스크톱 프로그램이자 명령줄 도구입니다. 후보가 나오는 텍스트나 발췌문의 문맥을 보여 주며, 출처에서 제공하는 경우 링크도 함께 표시합니다. 연구자는 이를 직접 읽고 판단할 수 있습니다. 화면은 한국어, 일본어, 중국어 간체·번체, 베트남어, 영어로 쓸 수 있으며, 화면 언어를 바꿔도 원문은 변환되거나 바뀌지 않습니다.

문법 판정기나 구문 분석기가 아니라 디지털 인문학 연구를 위한 보조 도구입니다. 후보를 모으고, 복합 검색에서는 구조적 단서에 따라 가능성 높은 검색결과와 가능성 낮은 검색결과로 나눌 뿐이며, 읽고 판단하는 일은 연구자의 몫입니다.

## 무엇을 검색하나요

3.1에서는 로컬 텍스트 폴더와 함께 5개 탐색 지역 18개 온라인 자료원을 제공합니다. 온라인 자료원은 제공처의 건수 상한에 따라 제한된 발췌문이나 서지 정보를 반환합니다.

| | 텍스트가 있는 곳 | 결과 |
|---|---|---|
| **내 텍스트** | 내 컴퓨터의 폴더: UTF-8 `.txt`·`.md` 파일, 본인 API 키로 Chinese Text Project(CTP/CText, ctext.org)에서 가져온 작품(`.txt`로 저장), 그리고 공공데이터포털에서 내려받은 기관 원문(국사편찬위원회, 한국고전번역원, 한국학중앙연구원 등)을 프로그램이 변환해 저장한 `.texts.jsonl` 묶음 파일 | 각 파일의 텍스트 전체를 검색. 검색 범위는 파일에 담긴 내용까지 |
| **온라인 발췌·서지 검색** | 5개 지역 18개 온라인 자료원(한국 8, 일본 4, 중국 1, 대만 4, 베트남 1). 인터넷 연결 필요 | 자료원이 돌려주는 검색어 주변 구절이나 서지 정보(대부분 양끝이 절단됨), 자료원·컬렉션별 건수 상한 적용 |

온라인 결과는 자료원이 돌려준 구절이고 자료원·컬렉션별 상한이 있으므로, 결과가 없다고 해서 그 문형이 쓰이지 않았다는 뜻은 아닙니다. 용례를 인용하기 전에 출처 링크를 열어 전체 원문을 확인하세요.

## 시작하기

### Windows (실행 파일)

1. [v3.1 릴리스 페이지](https://github.com/cobari/CPE-release/releases/tag/v3.1)에서 Windows x64용 실행 파일인 [cpe-gui.exe](https://github.com/cobari/CPE-release/releases/download/v3.1/cpe-gui.exe)를 내려받습니다.
2. 다운로드한 `cpe-gui.exe`를 두 번 클릭하면 검색 창이 열립니다. Python이나 uv를 설치할 필요가 없습니다.
3. Windows 실행 파일은 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/)을 사용합니다. 실행되지 않는 경우 링크에서 WebView2 런타임을 설치하세요.

> **참고**: `cpe-gui.exe` 단독 파일에는 검색 창만 포함되어 있습니다. 명령줄(CLI) 도구나 패턴 정의 파일은 포함되어 있지 않으므로, 명령줄 기능을 사용하려면 아래의 전체 배포 패키지(소스)를 이용하세요.

### macOS 및 Linux (배포 폴더 런처)

Windows 실행 파일은 macOS나 Linux에서 실행되지 않습니다. 전체 배포 패키지를 사용하세요:

1. [v3.1 릴리스 페이지](https://github.com/cobari/CPE-release/releases/tag/v3.1)에서 소스 코드(Source code .zip 또는 .tar.gz)를 내려받아 압축을 풉니다.
2. 압축을 푼 폴더 전체를 유지한 상태에서 다음 파일을 실행합니다:
   - **macOS**: `cpe-gui.command`를 두 번 클릭합니다. (터미널 창이 열리며 실행됩니다. 최초 실행 시 보안 확인 대화상자가 뜨면 마우스 오른쪽 버튼 클릭 후 '열기'를 선택하세요.)
   - **Linux**: `cpe-gui.sh`를 실행합니다. (파일 관리자에서 '실행' 또는 터미널에서 실행.)
   - 파일 탐색기에서 런처가 실행되지 않는 경우, 압축을 푼 배포 폴더에서 터미널을 열고 `sh cpe-gui.sh`를 실행할 수 있습니다.
3. 컴퓨터에 `uv` 도구가 설치되어 있지 않은 경우, 실행 스크립트가 공식 설치기를 통한 자동 설치 여부를 묻습니다(`y` 입력).
4. 첫 실행 시 필요한 Python 환경과 런타임 의존성을 자동으로 내려받으므로 인터넷 연결이 필요합니다.

## 빠른 첫 검색 (온라인 자료원)

1. **검색 소스**에서 검색할 폴더나 온라인 자료원에 체크하세요. 합해서 최대 네 곳을 고를 수 있습니다.
2. 상단의 책 아이콘과 프로그램 제목을 누르면 검색 화면으로 돌아갑니다.
3. 검색어를 적고 검색을 누르세요. 온라인 자료는 인터넷 연결이 필요하며, 자료원이 돌려준 범위 안에서만 결과를 보여 줍니다.

## 자료 준비 (내 텍스트 폴더)

- **검색 소스**에서 UTF-8 `.txt`·`.md` 파일이나 가져온 `.texts.jsonl` 자료가 있는 폴더를 추가하세요. 폴더를 네 곳까지 따로 등록할 수 있습니다. 등록을 해제해도 파일은 지워지지 않습니다.

- **가져오기**에서 새 원문을 저장할 폴더를 고른 뒤 **원문 자료 가져오기**를 누르세요. 저장할 폴더와 검색할 폴더의 선택은 서로 별개입니다. 아직 저장할 곳이 없으면 저장할 때 폴더를 고를 수 있습니다.

- 기관 자료, CTP, Project Gutenberg, NDL, CBETA·국사편찬위원회 XML, MPIWG 지리지 중에서 고르세요. 주소를 입력하는 곳에는 해당 사이트 링크가 있습니다. CTP의 장 하나는 접근키 없이 시도할 수 있지만, 작품 전체의 장 목록에는 본인의 CTP 접근키가 필요합니다. 실제 접근 허용 여부는 CTP가 정합니다.

- 미리보기를 제공하는 자료는 **미리보기**로 내용을 읽고, 남길 부분과 판본을 적은 뒤 확인란에 체크하세요. 온라인 자료는 **다운로드**, 이미 컴퓨터에 있는 파일은 **가져오기**를 누릅니다. 읽을 수 없는 부분은 사유와 함께 제외됩니다. 본문을 내려도 위쪽의 닫기 ×는 같은 자리에 남습니다.

## 검색 방법 및 주의사항

### 검색 방식

- **복합 검색 (기본)**: 문장 안에서 첫째 요소가 먼저 나오고 둘째 요소가 나중에 나오는 용례를 찾으며, 두 요소 사이에 다른 글자가 올 수 있습니다. ⇄ 버튼으로 두 요소의 순서를 바꿀 수 있습니다.
- **단일 검색**: 특정 단어나 구절을 검색합니다. `AND`, `OR`, `NOT`, `"정확한 구절"`, `NEAR/n`(글자 거리 제한) 연산자를 조합할 수 있습니다.


### 검색 대상 (동시 최대 4개 선택 가능)

내 컴퓨터의 텍스트 폴더와 5개 지역 18개 온라인 자료원 중에서 최대 네 곳을 골라 동시에 검색할 수 있습니다:

- **텍스트 폴더**: 고른 폴더와 그 안의 모든 하위 폴더에서 .txt·.md 파일(UTF-8 텍스트)과 .texts.jsonl 텍스트 묶음을 읽습니다. 텍스트 옆에 '파일명.txt.manifest.toml'을 두면 제목, 구두점 관례, 연대(era = "唐", year = 618, year_end = 907)를 지정할 수 있고, 없으면 파일 이름이 제목이 됩니다. 엑셀 등 다른 형식은 읽지 않습니다.
- **한국 (8)**:
  - **한국고전종합DB (ITKC)**: 한국고전종합DB의 고전원문·한국문집총간·일성록을 온라인으로 검색합니다. 검색어 주변 약 150자만 발췌해 제공하므로 결과에는 발췌문에 있는 내용만 표시됩니다. 제목을 누르면 ITKC의 해당 기록이 열립니다. 자료군마다 처음 100건만 확인하며 내용을 저장하지 않습니다.
  - **동양고전종합DB (사이버서당)**: 전통문화연구회 동양고전종합DB(사이버서당)를 Open API로 검색합니다. 서버에서 검색해 자료명, 설명문, 기사 링크가 담긴 서지 레코드를 반환합니다. 결과에는 반환된 텍스트와 사이버서당 원문 링크가 표시됩니다. 본문 전체나 문맥이 보장되지 않고, 반환 항목이 원문인지 번역문인지 확인되지 않으므로, 확인하지 못한 레코드는 후보로 남겨 둡니다. 처음 50건을 확인하며, 아무것도 저장하지 않습니다.
  - **한국사데이터베이스 통합검색**: 국사편찬위원회 한국사데이터베이스 통합검색을 시대와 자료 항목으로 검색합니다. 한 단어나 한 구절을 보내고 원문 탭의 첫 페이지, 최대 20행만 읽습니다. 제목·발췌·제공처 링크를 보여 주며 페이지 넘김, 기사 페이지 요청, 저장은 하지 않습니다. 전체 원문 패턴 매칭이 아닌 후보 검색입니다. 개인 비상업 연구용.
  - **조선왕조실록 · 국사편찬위원회 검색**: 국사편찬위원회 조선왕조실록 공개 검색창을 한 단어나 한 구절로 검색합니다. 원문 탭의 첫 페이지, 최대 50건만 읽고, 제목·발췌·기사 링크를 보여 줍니다. 전체 원문 패턴 매칭이 아니라 후보 검색이며, 발췌는 잘린 글입니다. 한 번에 한 검색만 보내며, 다음 결과 페이지를 요청하거나 저장하지 않습니다. 개인 비상업 연구용.
  - **동북아역사넷 검색**: 동북아역사재단 공개 사료라이브러리의 한 컬렉션을 한 단어나 한 구절로 검색합니다. 원문 결과의 첫 페이지, 최대 20행만 읽고 제목·발췌·제공처 링크를 보여 줍니다. 통합검색 화면은 건수만 제공하므로 먼저 컬렉션을 선택합니다. 전체 원문 패턴 매칭이 아닌 후보 검색이며, 페이지 넘김, 기사 페이지 요청, 저장은 하지 않습니다. 개인 비상업 연구용.
  - **국립문화유산연구원(NRICH) · 목간 판독문**: 공개 목간 자료를 최대 600건까지 불러와, 제공된 판독문에서 이두를 포함한 글자를 검색합니다. 불러온 범위만 검색하며 전체 데이터베이스를 검색하는 것은 아닙니다. 한 번 불러온 자료는 이후 검색에서 다시 사용합니다. 입력한 글자가 일치하는 자료를 후보로 제시하고 판독 기호는 제공된 그대로 유지합니다. 문형 적합성은 자동으로 판정하지 않으므로 원자료에서 확인하세요. 처음 불러올 때는 시간이 걸릴 수 있습니다. 개인의 비상업적 연구용이며 자료를 자동으로 파일에 저장하지 않습니다.
  - **한국학중앙연구원 고문서자료관**: 한국학중앙연구원 고문서자료관 archive.aks.ac.kr에서 단어나 구절 하나를 검색합니다. 원문 그룹의 첫 페이지 최대 20건만 확인하며, 각 결과에는 문서 제목, 검색어가 강조된 탈초 발췌문, 제공된 작성 날짜와 기록 페이지 링크가 표시됩니다. 발췌문은 양끝이 잘려 있으며 원문의 표기를 유지합니다. 이미지 뷰어나 기록의 전체 본문은 가져오지 않습니다. 확인한 표본은 로컬 Wikisource 목록 561개와 제목이 겹치지 않았지만, 연결된 기관 소장 자료와의 중복은 측정하지 않았습니다. 저장하지 않습니다. 자료 권리: 사이트 하단에 CC BY-NC-ND 2.0 KR 표식과 All Rights Reserved 안내가 함께 있습니다. 개인의 비상업적 용도로 이용하며 발췌문을 재배포하지 마세요. 기록 페이지에서 인용 형식을 복사할 수 있습니다.
  - **규장각 고문서 · 원문 검색**: 서울대학교 규장각의 고문서 DB(GMS)를 공백 없는 최대 80자의 검색어 하나로 검색합니다. 한 번의 응답에서 첫 20건만 읽어 제목·문서번호·발급자/수취자·출처 연대·종류와 함께, 응답에 직접 포함된 원문 발췌를 최대 600자 표시합니다. 일부 결과는 문서 정보만 제공하며 지연 로딩 본문은 추가 요청하지 않습니다. 탈초문에는 이두·불확실 표기·편집 기호가 포함될 수 있으며 언어와 문장 경계를 확정하지 않습니다. 문법적 일치나 등급을 부여하지 않습니다. 제목은 공식 원문 텍스트 뷰어를 엽니다. 고도서·편년사·의궤·근대정부기록류는 이 연결 범위 밖이며 다른 기관 고문서와의 전체 중복 범위는 미확인입니다. 추가 페이지·본문·이미지·번역을 가져오거나 저장하지 않습니다. 개인의 비상업적 연구에만 사용하고 규장각과 문서 출처를 명시하며 재배포하지 마세요.
- **일본 (4)**:

## 검색 결과 읽기

검색 결과는 개별 카드 형태로 표시되며, 원문이나 발췌문에 들어 있는 범위 안에서 해당 문장과 전후 문맥을 보여줍니다.

- **복합 검색 결과의 A/B 슬롯**:
  - **A**: 첫째 요소와 둘째 요소 사이에 위치한 구절입니다.
  - **B**: 둘째 요소 뒤에 이어지는 구절 후보입니다. (기계적으로 확정된 단일 경계가 아니므로 여러 후보가 제시될 수 있습니다.)
- **가능성 높은 검색결과 vs 가능성 낮은 검색결과**:
  - 복합 검색에서는 첫째와 둘째 요소가 바로 붙어 있어 A가 없는 경우, 둘째 요소가 더 가까이 있는 경우, A가 구두점(절 구분)을 넘는 경우 등 형태적·구조적 단서에 따라 두 그룹으로 자동 분류됩니다. 단일 검색에서는 모든 결과가 하나의 **검색결과** 그룹으로 표시됩니다.
  - **이 분류는 문법적 정답 여부의 판정이 아닙니다.** '가능성 낮음'으로 분류된 문장 중에도 실제 학술적으로 귀중한 특수 용례가 포함될 수 있으므로, 연구자의 문맥 검토가 항상 필요합니다.
- **참고**: 그래픽 검색 창에는 검색 결과를 CSV 파일로 내보내는 버튼이 없습니다. 표 형태의 결과 파일이 필요한 경우 아래의 명령줄(CLI) 인터페이스를 사용하세요.

## 고급: 소스에서 실행, 메타데이터, 명령줄 (CLI)

개발자나 명령줄 작업에 익숙한 연구자는 전체 배포 폴더에서 터미널 명령을 이용할 수 있습니다. 수동 설치가 필요한 경우 [공식 uv 설치 안내](https://docs.astral.sh/uv/getting-started/installation/)를 참고하세요.

### 소스에서 GUI 실행

```bash
uv sync --locked
uv run --locked cpe gui
# 또는 특정 텍스트 폴더를 바로 열기 (path/to/texts를 실제 폴더 경로로 변경):
uv run --locked cpe gui path/to/texts
```

### 서지 메타데이터 파일 (선택 사항)

텍스트 파일 옆에 사이드카 파일을 두어 서지 정보를 지정할 수 있습니다(예: 원문 파일명이 `my-text.txt`이면 메타데이터 파일명은 `my-text.txt.manifest.toml`로, 실제 원문 파일명 뒤에 `.manifest.toml`을 붙임). 선택 필드로 `title`, `edition`, `era`, `year`, `year_end`를 지원합니다. 이 파일이 없으면 파일 이름이 그대로 제목이 되며, 연대 정보가 없어도 검색에는 아무런 지장이 없습니다.

### 명령줄 검색 (CLI)

CLI 검색은 CSV, JSONL 및 실행 메타데이터 파일을 출력합니다. `my-text.txt`는 실제 텍스트 파일 경로로 바꾸어 실행하세요:

```bash
# 기본 도움말
uv run --locked cpe --help

# 패턴 파일과 개별 텍스트 파일을 지정하여 문형 검색 실행
# (--out results 는 results.csv, results.jsonl, results.run.json 파일 생성 접두사입니다)
uv run --locked cpe match patterns/mvp.toml my-text.txt --out results

# 한국고전종합DB CLI 검색 도구
uv run --locked python itkc_search.py --help
```

### 로컬 MCP 서버 (AI 연동)

미공개 3.1 릴리스 후보에는 공식 Python SDK v2 기반의 로컬 stdio MCP(Model Context Protocol) 서버가 포함되어 있습니다. 4개 로컬 라이브러리 슬롯, 18개 온라인 소스 어댑터, 제공처 카탈로그, 단계별 ITKC 컬렉션 세션, 한문 문형 DSL 검색, 안전한 코퍼스 가져오기 파이프라인 및 CSV/JSONL 직접 내보내기를 다루는 20개 전용 도구를 제공합니다.

`ash
# stdio 기반 MCP 서버 실행 (선택적 'mcp' 추가 기능 필요)
uv run --extra mcp cpe mcp path/to/texts
`

독립 실행형 윈도우 패키지에는 동일한 인수를 받는 cpe-mcp.exe가 함께 포함되어 있습니다. 서버는 표준 입출력(stdin/stdout)을 통해 통신하며 GUI 창이나 HTTP 서버는 열리지 않습니다. 자세한 내용은 [MCP 설치·옵션·20개 도구 안내](docs/mcp.md)와 [3.1 기능 대응표](docs/mcp-parity.md)를 참고하세요. 본 후보 구현은 특정 상용 AI 클라이언트(Claude Desktop, Claude Code 등)나 외부 라이브 서비스에 대한 공식 인증을 주장하지 않습니다.

## 자주 묻는 질문 (FAQ)

**Q1. 텍스트 파일이 열리지 않거나 읽히지 않습니다.**

A. 본 프로그램은 UTF-8 인코딩의 일반 텍스트 파일(`.txt`, `.md`)만 읽습니다. Word(`.docx`), HWP, PDF 등의 파일 확장자만 `.txt`로 변경한 파일은 읽을 수 없으므로, 해당 프로그램에서 텍스트 파일(UTF-8)로 새로 저장하여 사용하세요.

**Q2. 검색 결과가 전혀 나오지 않습니다.**

A. **검색 소스**에서 원하는 자료에 체크했는지, 폴더를 정상적으로 읽었는지 확인하세요. NDL에는 두 글자 이상의 요소가 적어도 하나 필요합니다. 검색어를 단순하게 바꿔 보세요. 결과가 없어도 역사적으로 그 용례가 없었다는 뜻은 아닙니다.

**Q3. 온라인 검색 중 오류가 발생합니다.**

A. 인터넷 연결과 자료원의 오류 안내를 확인하세요. 실행 중 요청 횟수 제한은 자료원을 보호하기 위한 이 프로그램의 제한이며, 자료원 자체의 정책을 뜻하지 않습니다. 복잡한 온라인 검색식은 해당 자료원에 보낼 수 있는 필수 검색어가 있는지에 따라서도 달라집니다. 허용된 원문을 내려받아 로컬에서 검색할 수도 있습니다.

**Q4. Windows에서 실행 파일(cpe-gui.exe)이 열리지 않습니다.**

A. 배포된 `cpe-gui.exe`는 64비트 Windows(x64)용입니다. 실행 시 반응이 없거나 오류가 발생하는 경우 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/)이 설치되어 있는지 확인하고 설치해 주세요.
