# Classic Pattern Explorer 1.0

[English](README.md) | [한국어](README.ko.md) | [日本語](README.ja.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md)

Classic Pattern Explorer 是一款用于在文言文（汉文，Literary Sinitic）原文中检索特定句式结构（如“以…爲”、“雖…而”等）并在桌面图形窗口或命令行中查看用例及其上下文的研究辅助工具。界面支持韩语、日语、简体中文、繁体中文和英语。切换界面语言绝不会转换或改动原文文本。

本程序并非机械的语法判决器，而是旨在从海量文献中提取句式候选句，并依据形态结构线索进行归类，以协助学者直接研读原文与上下文的研究工具。

## 快速入门

### Windows（可执行文件）

1. 访问 [v1.0 发布页面](https://github.com/cobari/CPE-release/releases/tag/v1.0) 并下载 Windows x64 专用可执行文件 [cpe-gui.exe](https://github.com/cobari/CPE-release/releases/download/v1.0/cpe-gui.exe)。
2. 双击 `cpe-gui.exe` 即可打开检索窗口，无需安装 Python 或 uv。
3. Windows 可执行文件依赖 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/)。若无法启动，请通过链接安装 WebView2 运行时。

> **注意**：单独下载的 `cpe-gui.exe` 仅包含图形检索窗口，不包含命令行工具及模式定义文件。若需使用命令行（CLI）功能，请使用下方的完整发行包（源码）。

### macOS 与 Linux（发行包启动脚本）

Windows 可执行文件无法在 macOS 或 Linux 上直接运行。请使用完整发行包：

1. 从 [v1.0 发布页面](https://github.com/cobari/CPE-release/releases/tag/v1.0) 下载源码压缩包（`Source code .zip` 或 `.tar.gz`）并解压。
2. 保持解压后的完整文件夹结构，运行对应的启动脚本：
   - **macOS**：双击 `cpe-gui.command`。（将在终端窗口中启动。首次运行若弹出安全提示，请右键点击并选择“打开”。）
   - **Linux**：运行 `cpe-gui.sh`。（在文件管理器中选择“运行”或在终端中执行。）
   - 若在文件管理器中无法启动，可在解压后的文件夹中打开终端并执行 `sh cpe-gui.sh`。
3. 若系统尚未安装 `uv`，启动脚本会提示是否使用官方安装程序自动安装（输入 `y` 确认）。
4. 首次运行会自动下载所需的 Python 环境和运行时依赖（需要联网）。

## 首次检索体验（在线文献源）

即使本地尚未准备好文本文件，只要连接网络，您也可以直接通过在线数据库体验检索功能：

1. 启动程序后，点击右上角的 **设置** 按钮。
2. 在 **搜索范围** 中先勾选 **韩国古典综合数据库 (ITKC)**，然后再取消勾选 **我的文本文件夹**，最后点击设置窗口底部的 **关闭** 按钮。
3. 在主界面默认的 **组合检索** 模式下：
   - **第一要素**：输入 `以`
   - **第二要素**：输入 `爲`
4. 点击 **检索** 按钮，在线数据库返回的候选句子即会展示在面板中。（点击 ⇄ 按钮可快速交换第一要素与第二要素的位置。）

## 语料准备（我的文本文件夹）

若要检索自己的文言文本，请在设置对话框的 **搜索范围** 中勾选 **我的文本文件夹**。

### 1. 打开本地文本文件夹

- 点击 **打开文本文件夹…** 按钮，选择包含 `.txt` 或 `.md` 文件的文件夹。程序仅读取 UTF-8 编码的纯文本，并加载所有子文件夹中的文件。不支持 Excel 等其他格式。
- 程序会记住上次选择的文本文件夹。

### 2. 下载机构原文资料（开放数据）

若手头没有文言文本，可以直接在程序内下载韩国公共机构开放的大规模古典文献：

1. 点击设置中的 **下载机构原文资料…** 按钮。
2. **1. 机构**：选择国史编纂委员会（三国史记、高丽史、备边司誊录等）或韩国古典翻译院（文集、笔记等）。
3. **2. 资料**：选择文献集，指定 **3. 保存文件夹**，然后点击 **下载**。
4. 下载与格式转换将在后台自动进行，完成后该文件夹将自动作为当前检索库打开。

若遇到门户网络故障或验证码提示，请点击 **在门户查看** 手动下载 ZIP，再使用 **导入已下载的 ZIP…** 功能。

### 3. 从 CTP (中国哲学书电子化计划) 导入

- 点击设置中的 **从CTP导入…** 按钮，输入 `ctext.org` 上的作品或章节地址，各章节将保存为纯文本文件以供检索。
- 须先在本地打开一个用于保存的文本文件夹。CTP 的绝大多数文献仅向拥有 API 密钥的用户开放，请在 `ctext.org` 账户中申请个人 API 密钥并在此保存。

## 检索方法与注意事项

### 检索方式

- **组合检索（默认）**：在句子中先出现第一要素，再出现第二要素，两者之间可以有文字。点击 ⇄ 可交换两要素的位置。
- **单项检索**：查找包含特定词语的句子。支持组合布尔运算 `AND`、`OR`、`NOT`、精确短语 `"..."` 及字符间距限制 `NEAR/n`。（在线检索不支持 `OR` 运算符。）

### 检索范围（最多可同时选择4个）

- **我的文本文件夹**：检索本地纯文本语料。
- **韩国古典综合数据库 (ITKC)**：在线检索古典原文与文集丛刊。返回检索词前后约150字的截断摘录，每个集合检查前100条记录。
- **日本国立国会图书馆 (NDL)**：检索古籍 OCR 文本（将古籍图像识别为字符的文本）。**必须至少包含一个两个字及以上的要素**（不支持纯单字检索，例如仅用 `以` 和 `爲` 无法在 NDL 检索）。返回无标点的 OCR 摘录（可能存在识别误差），检查前50册。
- **CBETA 汉文佛典**：在线检索佛典。返回命中词前后各约40字的摘录，检查前50卷。

在线数据源返回的是检索词周边的**局部摘录**而非完整原书，且每个数据源与集合有检查数量上限（50～100条）。因此，**“无检索结果”并不等同于该历史文献中绝对不存在此句式用例。** 在论文引用前，请务必点击卡片上的文献标题链接，查看原始书影或完整页面。

## 检索结果解读

每个匹配项以卡片形式展示，并在原文或摘录包含的范围内显示目标句及其上下文。

- **组合检索结果槽位**：
  - **A 槽**：第一要素与第二要素之间的夹词部分。
  - **B 槽**：第二要素之后的候选用词范围（程序不会机械断定唯一边界，可能会列出若干候选切分）。
- **较可能符合的结果 vs 较不可能符合的结果**：
  - 在组合检索中，程序根据形态特征自动分组（如两要素紧邻无 A 槽、存在更近的第二要素、A 槽跨越了分句标点等）。在单项检索中，所有匹配结果均展示在单一的 **检索结果** 分组中。
  - **此分类并非语法正误判定。** 被归入“较不可能符合”的结果中可能依然包含极有价值的特殊文言语法现象，必须由研究者亲自研读考证。
- **说明**：图形检索窗口中没有将结果导出为 CSV 文件的按钮。若学术研究需要表格格式的数据，请使用下方的命令行（CLI）工具。

## 高级进阶：源码运行、元数据与命令行 (CLI)

熟悉终端操作的学者或开发者可在完整发行包目录下使用 `uv` 运行。手动安装指南请参阅 [官方 uv 安装文档](https://docs.astral.sh/uv/getting-started/installation/)。

### 从源码运行 GUI

```bash
uv sync --locked
uv run --locked cpe gui
# 或直接指定文本文件夹 (请将 path/to/texts 替换为实际路径)：
uv run --locked cpe gui path/to/texts
```

### 文献元数据伴随文件（可选）

在文本文件旁放置配置文件可指定详细文献信息（例如原文文件名若为 `my-text.txt`，则在实际文件名后附加 `.manifest.toml` 命名为 `my-text.txt.manifest.toml`）。支持的可选字段包括 `title`、`edition`、`era`、`year` 与 `year_end`。若不提供此文件，程序默认以文件名作为篇名，缺失年代信息不会影响检索。

### 命令行检索 (CLI)

命令行检索支持导出 CSV、JSONL 及运行元数据。请将 `my-text.txt` 替换为实际文件路径：

```bash
# 查看帮助
uv run --locked cpe --help

# 指定模式定义文件和单个 UTF-8 文本文件执行句式匹配
# (--out results 是生成 results.csv、results.jsonl 和 results.run.json 的输出前缀)
uv run --locked cpe match patterns/mvp.toml my-text.txt --out results

# 韩国古典综合数据库命令行工具
uv run --locked python itkc_search.py --help
```

## 常见问题 (FAQ)

**Q1. 文本文件无法打开或无法读取。**

A. 本程序仅读取 UTF-8 编码的纯文本文件（`.txt`、`.md`）。直接将 Word（`.docx`）、HWP 或 PDF 的扩展名改为 `.txt` 无法转换为纯文本，请在相应软件中重新另存为 UTF-8 文本文件。

**Q2. 检索结果没有任何显示。**

A. 请检查设置中是否正确勾选了检索范围（我的文本文件夹或在线数据库），并确认是否已打开文本文件夹。若检索 NDL，须保证至少一个要素为两个字以上。可尝试简化检索词。无检索结果并不意味着文献中不存在该句式。

**Q3. 在线检索时提示错误。**

A. 请检查网络连接。在线数据源（ITKC、NDL、CBETA）的200次请求上限并非数据源本身的策略，而是本程序为保护数据源而在每次运行会话中设置的安全限制；达到上限后重新启动窗口即可重置。此外，在线检索不支持 `OR` 运算符，请检查检索式。

**Q4. 在 Windows 上可执行文件 (cpe-gui.exe) 无法启动。**

A. 发布的 `cpe-gui.exe` 适用于 64 位 Windows (x64)。若双击无反应或报错，请确认系统是否已安装 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/) 并进行安装。
