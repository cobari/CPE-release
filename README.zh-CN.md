# Classic Pattern Explorer 3.0.0

[English](README.md) | [한국어](README.ko.md) | [日本語](README.ja.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [Tiếng Việt](README.vi.md)

Classic Pattern Explorer 是一款桌面程序兼命令行工具，用于在文言文（汉文，Literary Sinitic）原文中查找“以…爲”“雖…而”等句式的候选用例。每个候选都会连同该文本或数据源摘录所含的上下文一并显示（出处有链接时也附上链接），供研究者亲自阅读和判断。界面支持韩语、日语、简体中文、繁体中文、越南语和英语；切换界面语言不会转换或改动原文。

它不是语法判定器或句法分析器，而是面向数字人文研究的辅助工具：只负责收集候选，并在组合检索中按结构线索分为“较可能符合的结果”和“较不可能符合的结果”，阅读和判断仍由研究者完成。

## 可以检索什么

3.0.0版本支持本地文本文件夹，并按5个国家与地区提供18个在线资料源。在线数据源依据提供方的数量上限返回有限的摘录或书目记录。

| | 文本所在 | 结果 |
|---|---|---|
| **自己的文本** | 本机文件夹：UTF-8 `.txt`、`.md` 文件，用本人 API 密钥从中国哲学书电子化计划（Chinese Text Project，CTP/CText，ctext.org）导入的作品（保存为 `.txt`），以及程序转换从韩国公共数据门户下载的机构原文（国史编纂委员会、韩国古典翻译院、韩国学中央研究院等）后保存的 `.texts.jsonl` 合集文件 | 检索每个文件的全部文本；检索范围以文件内容为限 |
| **在线摘录与书目检索** | 5个地区的18个在线资料源（韩国 8、日本 4、中国 1、台湾 4、越南 1）；需要联网 | 数据源返回的命中处前后段落或书目记录（常在两端截断），受各数据源检索上限约束 |

在线结果是数据源返回的段落或记录，受各数据源上限限制，因此没有结果并不能证明该句式从未出现。引用用例前，请打开出处链接核对完整原文。

## 快速入门

### Windows（可执行文件）

1. 访问 [v3.0.0 发布页面](https://github.com/cobari/CPE-release/releases/tag/v3.0.0) 并下载 Windows x64 专用可执行文件 [cpe-gui.exe](https://github.com/cobari/CPE-release/releases/download/v3.0.0/cpe-gui.exe)。
2. 双击 `cpe-gui.exe` 即可打开检索窗口，无需安装 Python 或 uv。
3. Windows 可执行文件依赖 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/)。若无法启动，请通过链接安装 WebView2 运行时。

> **注意**：单独下载的 `cpe-gui.exe` 仅包含图形检索窗口，不包含命令行工具及模式定义文件。若需使用命令行（CLI）功能，请使用下方的完整发行包（源码）。

### macOS 与 Linux（发行包启动脚本）

Windows 可执行文件无法在 macOS 或 Linux 上直接运行。请使用完整发行包：

1. 从 [v3.0.0 发布页面](https://github.com/cobari/CPE-release/releases/tag/v3.0.0) 下载源码压缩包（`Source code .zip` 或 `.tar.gz`）并解压。
2. 保持解压后的完整文件夹结构，运行对应的启动脚本：
   - **macOS**：双击 `cpe-gui.command`。（将在终端窗口中启动。首次运行若弹出安全提示，请右键点击并选择“打开”。）
   - **Linux**：运行 `cpe-gui.sh`。（在文件管理器中选择“运行”或在终端中执行。）
   - 若在文件管理器中无法启动，可在解压后的文件夹中打开终端并执行 `sh cpe-gui.sh`。
3. 若系统尚未安装 `uv`，启动脚本会提示是否使用官方安装程序自动安装（输入 `y` 确认）。
4. 首次运行会自动下载所需的 Python 环境和运行时依赖（需要联网）。

## 首次检索体验（在线文献源）

1. 在**检索来源**中勾选要检索的文件夹或在线数据源，合计最多四项。
2. 点击顶部的书本图标和程序名称，返回检索页面。
3. 输入检索词并点击检索。在线数据源需要网络连接；结果只覆盖数据源返回的范围。

## 语料准备（我的文本文件夹）

- 在**检索来源**中添加存有UTF-8 `.txt`、`.md`或已导入`.texts.jsonl`的文件夹。可分别登记四个文件夹；移除登记不会删除文件。

- 打开**导入**，选择新原文的保存文件夹，再点击**导入原文资料**。保存位置和检索对象分别选择；尚未指定时可在保存时选择文件夹。

- 选择机构公开资料、CTP、Project Gutenberg、NDL、CBETA或韩国国史编纂委员会XML、MPIWG地方志。地址输入处提供原网站链接。CTP单章可尝试免密钥访问，但整部作品的章目需要自己的CTP密钥，能否访问由CTP决定。

- 对支持预览的资料，点击**预览**查看内容，选择保留部分、填写版本并勾选确认项。在线资料使用**下载**，电脑上已有的文件使用**导入**。不支持的内容会注明原因并排除。滚动正文时顶部的关闭×始终保留。

## 检索方法与注意事项

### 检索方式

- **组合检索（默认）**：在句子中先出现第一要素，再出现第二要素，两者之间可以有文字。点击 ⇄ 可交换两要素的位置。
- **单项检索**：查找包含特定词语的句子。支持组合布尔运算 `AND`、`OR`、`NOT`、精确短语 `"..."` 及字符间距限制 `NEAR/n`。

## 检索结果解读

每个匹配项以卡片形式展示，并在原文或摘录包含的范围内显示目标句及其上下文。

- **组合检索结果槽位**：
  - **A 槽**：第一要素与第二要素之间的夹词部分。
  - **B 槽**：第二要素之后的候选用词范围（程序不会机械断定唯一边界，可能会列出若干候选切分）。
- **较可能符合的结果 vs 较不可能符合的结果**：
  - 在组合检索中，程序根据形态特征自动分组（如两要素紧邻无 A 槽、存在更近的第二要素、A 槽跨越了分句标点等）。在单项检索中，所有匹配结果均展示在单一的 **检索结果** 分组中。
  - **此分类并非语法正误判定。** 被归入“较不可能符合”的结果中可能依然包含极有价值的特殊文言语法现象，必须由研究者亲自研读考证。
- **说明**：图形检索窗口中没有将结果导出为 CSV 文件的按钮。若学术研究需要表格格式的数据，请使用下方的命令行（CLI）工具。

## 高级进阶：源码运行、元数据与命令行 (CLI)

熟悉终端操作的学者或开发者可在完整发行包目录下使用 `uv` 运行。手动安装指南请参阅 [官方 uv 安装文档](https://docs.astral.sh/uv/getting-started/installation/)。

### 从源码运行 GUI

```bash
uv sync --locked
uv run --locked cpe gui
# 或直接指定文本文件夹 (请将 path/to/texts 替换为实际路径)：
uv run --locked cpe gui path/to/texts
```

### 文献元数据伴随文件（可选）

在文本文件旁放置配置文件可指定详细文献信息（例如原文文件名若为 `my-text.txt`，则在实际文件名后附加 `.manifest.toml` 命名为 `my-text.txt.manifest.toml`）。支持的可选字段包括 `title`、`edition`、`era`、`year` 与 `year_end`。若不提供此文件，程序默认以文件名作为篇名，缺失年代信息不会影响检索。

### 命令行检索 (CLI)

命令行检索支持导出 CSV、JSONL 及运行元数据。请将 `my-text.txt` 替换为实际文件路径：

```bash
# 查看帮助
uv run --locked cpe --help

# 指定模式定义文件和单个 UTF-8 文本文件执行句式匹配
# (--out results 是生成 results.csv、results.jsonl 和 results.run.json 的输出前缀)
uv run --locked cpe match patterns/mvp.toml my-text.txt --out results

# 韩国古典综合数据库命令行工具
uv run --locked python itkc_search.py --help
```

## 常见问题 (FAQ)

**Q1. 文本文件无法打开或无法读取。**

A. 本程序仅读取 UTF-8 编码的纯文本文件（`.txt`、`.md`）。直接将 Word（`.docx`）、HWP 或 PDF 的扩展名改为 `.txt` 无法转换为纯文本，请在相应软件中重新另存为 UTF-8 文本文件。

**Q2. 检索结果没有任何显示。**

A. 请在**检索来源**确认已勾选所需资料且文件夹已加载。NDL至少需要一个两字以上的检索元素。可简化检索词重试；无结果不代表历史上不存在该用例。

**Q3. 在线检索时提示错误。**

A. 请检查网络和数据源的错误提示。每次运行的请求上限是本程序为保护数据源设置的限制。复杂在线检索式也受可向该数据源发送的必需检索词限制。还可下载允许使用的原文，在本地检索。

**Q4. 在 Windows 上可执行文件 (cpe-gui.exe) 无法启动。**

A. 发布的 `cpe-gui.exe` 适用于 64 位 Windows (x64)。若双击无反应或报错，请确认系统是否已安装 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/) 并进行安装。
