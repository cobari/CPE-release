# Classic Pattern Explorer 2.0

[English](README.md) | [한국어](README.ko.md) | [日本語](README.ja.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md)

Classic Pattern Explorer は、漢文（Literary Sinitic）の原文から「以…爲」「雖…而」のような文型の候補を探すデスクトップアプリ兼コマンドラインツールです。候補ごとに、そのテキストや資料源の抜粋が含む文脈を、出典にリンクがあればそのリンクも添えて示すので、研究者が自分で読んで判断できます。画面は韓国語・日本語・簡体字中国語・繁体字中国語・英語に対応し、画面の言語を変えても原文が変換・改変されることはありません。

文法の判定機や構文解析器ではなく、人文情報学（デジタル・ヒューマニティーズ）のための研究支援ツールです。候補を集め、複合検索では構造的な手がかりにより「該当する可能性が高い結果」と「該当する可能性が低い結果」に分けるだけで、読んで判断するのは研究者自身です。

## 検索できるもの

2.0ではITKC・NDL・CBETAに加え、東洋古典総合DBとDocuSkyの佛寺志靈應故事も検索します。本文が返らない東洋古典総合DBの候補は出典リンク付きの未確認候補として区別します。MPIWG地方志は全体のオンライン検索ではなく、選んだ章の一部をローカルに取り込む方式です。

| | テキストのある場所 | 得られるもの |
|---|---|---|
| **自分のテキスト** | 自分のパソコンのフォルダー：UTF-8 の `.txt`・`.md` ファイル、自分の API キーで Chinese Text Project（CTP/CText、ctext.org）から取り込んだ作品（`.txt` で保存）、そして韓国の公共データポータルからダウンロードした公的機関の原文（国史編纂委員会、韓国古典翻訳院）をプログラムが変換して保存する `.texts.jsonl` のまとめファイル | 各ファイルのテキスト全体を検索。検索範囲はファイルの内容まで |
| **オンライン抜粋検索** | 韓国古典総合DB（ITKC：原文コレクションの古典原文と韓国文集叢刊。朝鮮王朝実録・承政院日記・日省録などの翻訳コレクションは検索しません）、国立国会図書館（NDL、OCR テキスト）、CBETA 漢文仏典。インターネット接続が必要 | 資料源が返すヒット前後の一節。両端が切れていることが多く、資料源・コレクションごとに最初の50〜100件（レコード・資料・巻）まで |

オンラインの結果は資料源が返した一節で、資料源・コレクションごとの上限があるため、結果がないことは、その文型が使われていないことの証明にはなりません。用例を引用する前に、出典のリンクを開いて全文を確認してください。

## 起動方法

### Windows（実行ファイル）

1. [v2.0 リリースページ](https://github.com/cobari/CPE-release/releases/tag/v2.0) から Windows x64 用の実行ファイル [cpe-gui.exe](https://github.com/cobari/CPE-release/releases/download/v2.0/cpe-gui.exe) をダウンロードします。
2. ダウンロードした `cpe-gui.exe` をダブルクリックすると検索ウィンドウが開きます。Python や uv をインストールする必要はありません。
3. Windows 実行ファイルは [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/) を使用します。起動しない場合はリンク先から WebView2 ランタイムをインストールしてください。

> **注意**: 単体の `cpe-gui.exe` には検索ウィンドウのみが含まれています。コマンドライン（CLI）ツールやパターン定義ファイルは同梱されていないため、CLI 機能を利用する場合は下記の配布パッケージ（ソース）をご利用ください。

### macOS および Linux（配布フォルダーのランチャー）

Windows 実行ファイルは macOS や Linux では動作しません。配布パッケージ全体をご利用ください：

1. [v2.0 リリースページ](https://github.com/cobari/CPE-release/releases/tag/v2.0) からソースコード（Source code .zip または .tar.gz）をダウンロードし、展開します。
2. 展開したフォルダー全体を保持したまま、以下のファイルを実行します：
   - **macOS**: `cpe-gui.command` をダブルクリックします。（ターミナル画面が開いて実行されます。初回起動時にセキュリティ警告が表示された場合は、右クリックして「開く」を選択してください。）
   - **Linux**: `cpe-gui.sh` を実行します。（ファイルマネージャーで「実行」またはターミナルから実行。）
   - ファイルマネージャーから起動できない場合は、展開したフォルダーでターミナルを開き `sh cpe-gui.sh` を実行してください。
3. コンピューターに `uv` がインストールされていない場合、公式インストーラーによる自動インストールの確認が表示されます（`y` を入力して承認）。
4. 初回実行時に必要な Python 環境および依存関係が自動的にダウンロードされるため、インターネット接続が必要です。

## 最初の検索（オンライン資料）

1. **検索ソース**で検索するフォルダーやオンライン資料を選びます。合わせて最大4件まで選べます。
2. 上部の本のアイコンとアプリ名を押すと検索画面に戻ります。
3. 検索語を入力して検索を押します。オンライン資料にはインターネット接続が必要で、資料元が返した範囲内を検索します。

## 資料の準備（自分のテキストフォルダー）

- **検索ソース**でUTF-8の`.txt`・`.md`、または取り込んだ`.texts.jsonl`があるフォルダーを追加します。4つのフォルダーを別々に登録できます。登録を外してもファイルは削除されません。

- **取り込み**で新しい原文の保存先を選び、**原文資料の取り込み**を押します。保存先と検索対象の選択は別です。未指定なら保存時にフォルダーを選べます。

- 機関の公開資料、CTP、Project Gutenberg、NDL、CBETA・韓国国史編纂委員会のXML、MPIWGの地方志から選びます。アドレス入力欄には資料元へのリンクがあります。CTPの単独の章はキーなしで試せますが、作品全体の章一覧には自分のCTPキーが必要です。アクセス可否はCTPが決めます。

- 対応する資料は**プレビュー**で内容を読み、残す部分と底本情報を指定して確認欄にチェックします。オンライン資料は**ダウンロード**、手元のファイルは**取り込む**を押します。対応できない部分は理由とともに除外されます。本文をスクロールしても上部の×で閉じられます。

## 検索方法と注意事項

### 検索方法

- **複合検索（既定）**: 文の中で第1要素が先に出現し、その後に第2要素が現れる用例を検索します（2つの要素の間に文字が挟まっていても構いません）。⇄ ボタンで要素の順序を入れ替えられます。
- **単一検索**: 特定の単語や語句を検索します。`AND`、`OR`、`NOT`、`"正確な語句"`、`NEAR/n`（文字間距離制限）などの演算子を組み合わせることができます。

### 検索対象（同時に最大4つまで選択可能）

- **自分のテキストフォルダー**: 手元のローカルテキストを検索します。
- **韓国古典総合DB (ITKC)**: 古典原文および韓国文集叢刊をオンライン検索します。検索語の前後約150文字の抜粋（両端切断）が返され、コレクションごとに最初の100件まで確認します。
- **国立国会図書館 (NDL)**: 古典籍の OCR テキスト（本の画像を文字として認識したテキスト）を検索します。**必ず2文字以上の要素が少なくとも1つ含まれている必要があります**（1文字単独の検索は不可。例えば「以」と「爲」のみでは NDL 検索は行えません）。句読点がなく誤認識が含まれる可能性があるため、最初の50冊まで確認します。
- **CBETA 漢文大蔵経**: 仏典をオンライン検索します。検索語の前後各40文字の抜粋が返され、最初の50巻まで確認します。

オンライン資料は全文ではなく検索語周辺の**抜粋**を返し、資料提供元およびコレクションごとに確認件数の上限（50〜100件）があります。そのため、**「検索結果なし」であっても、その文献全体に用例が存在しないことを証明するものではありません。** 論文等に引用する前に、必ず結果カードの題名リンクから原本画像や原文ページを直接確認してください。

## 検索結果の読み方

各用例はカード形式で表示され、原文または抜粋に含まれる範囲で該当文と前後の文脈が提示されます。

- **複合検索結果の A/B スロット**:
  - **A**: 第1要素と第2要素の間に挟まれた部分です。
  - **B**: 第2要素の後に続く語句の候補です（機械的に確定された単一の境界ではなく、複数の候補範囲が示される場合があります）。
- **該当する可能性が高い結果 vs 該当する可能性が低い結果**:
  - 複合検索では、第1要素と第2要素が隣接してAが存在しない場合、より近い第2要素がある場合、Aが句読点（節の区切り）をまたいでいる場合など、構造的な手がかりに基づいて自動分類されます。単一検索ではすべての結果が1つの **検索結果** グループにまとめて表示されます。
  - **この分類は文法的な正否の判定ではありません。**「可能性が低い」と分類された結果の中にも研究上重要な用例が含まれることがあるため、研究者自身による文脈の精読が不可欠です。
- **注意**: GUI ウィンドウには結果を CSV ファイルに書き出すボタンはありません。表形式のデータが必要な場合は、下記のコマンドライン（CLI）をご利用ください。

## 上級者向け：ソースからの実行、メタデータ、コマンドライン（CLI）

シェル操作に慣れた研究者や開発者は、配布フォルダーから `uv` を用いて直接実行できます。手動インストールの手順は [公式 uv インストール案内](https://docs.astral.sh/uv/getting-started/installation/) を参照してください。

### ソースからの GUI 起動

```bash
uv sync --locked
uv run --locked cpe gui
# または直接テキストフォルダーを指定して起動 (path/to/texts を実際のパスに置き換えてください)：
uv run --locked cpe gui path/to/texts
```

### 書誌メタデータファイル（任意）

テキストファイルの隣にサイドカーファイルを置くことで書誌情報を指定できます（例: 原文ファイル名が `my-text.txt` の場合、実際のファイル名の末尾に `.manifest.toml` を付けた `my-text.txt.manifest.toml` とします）。任意のフィールドとして `title`、`edition`、`era`、`year`、`year_end` をサポートしています。このファイルがない場合はファイル名がそのまま題名となり、年代情報がなくても検索には支障ありません。

### コマンドライン（CLI）検索

CLI 検索では CSV、JSONL、実行メタデータファイルが出力されます。`my-text.txt` を実際のファイルパスに置き換えて実行してください：

```bash
# 全般的なヘルプの表示
uv run --locked cpe --help

# パターン定義ファイルと個別の UTF-8 テキストファイルを指定して検索
# （--out results は results.csv / results.jsonl / results.run.json 生成接頭辞です）
uv run --locked cpe match patterns/mvp.toml my-text.txt --out results

# ITKC コマンドライン検索ツール
uv run --locked python itkc_search.py --help
```

## よくある質問（FAQ）

**Q1. テキストファイルが開かない、または読み込めません。**

A. 本ツールは UTF-8 形式のプレーンテキストファイル（`.txt`、`.md`）のみを読み込みます。Word（`.docx`）、HWP、PDF などの拡張子を `.txt` に変更しただけのファイルは読み込めないため、各アプリケーションから UTF-8 のテキストファイルとして保存し直してください。

**Q2. 検索結果が全く表示されません。**

A. **検索ソース**で対象資料が選ばれているか、フォルダーが読み込まれたか確認してください。NDLには2文字以上の要素が少なくとも1つ必要です。検索語を簡単にして試してください。結果がないことは歴史的な不在の証明ではありません。

**Q3. オンライン検索でエラーが発生します。**

A. 接続と資料元のエラーを確認してください。セッション中のリクエスト上限は資料元を保護するための本アプリの制限です。複雑な検索式は資料元に送れる必須語の有無にも左右されます。利用が認められた原文を取り込み、ローカルで検索することもできます。

**Q4. Windows で実行ファイル（cpe-gui.exe）が起動しません。**

A. 配布されている `cpe-gui.exe` は 64 ビット Windows（x64）専用です。起動しない場合は、[Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/) がインストールされているか確認し、インストールを行ってください。
