Máy chủ stdio MCP cục bộ cho quy trình nghiên cứu AI

Sử dụng Python MCP SDK v2 chính thức để cung cấp 20 công cụ nghiên cứu qua stdin/stdout cục bộ, khóa mặc định việc trả về văn bản gốc cho tới khi máy chủ nhận quyền khởi động tường minh.

Mặc định chỉ trả về tham chiếu và siêu dữ liệu (text_withheld: true). Muốn trả về văn bản cục bộ hoặc đoạn trích trực tuyến, phải chỉ định --allow-source-text khớp với từng nguồn.

Cài đặt và kiểm tra trước khi chạy

Cài Python 3.11+ và uv, đồng bộ gói tùy chọn mcp và kiểm tra tham số cục bộ trước khi kết nối ứng dụng AI (tệp cpe-mcp.exe trên Windows dùng cùng các cờ):

uv sync --extra mcp
uv run --extra mcp cpe mcp --version
uv run --extra mcp cpe mcp path/to/texts --doctor --json
uv run --extra mcp cpe mcp path/to/texts --enable-online itkc --itkc-log itkc-requests.jsonl --print-config
uv run --extra mcp cpe mcp path/to/texts --allow-source-text local

Mẫu cấu hình máy khách (mặc định chỉ trả tham chiếu)

Dán đoạn JSON dưới đây vào cấu hình máy chủ stdio MCP. Khi thiếu --allow-source-text, các công cụ chỉ trả về mã định danh, tiêu đề, liên kết và siêu dữ liệu:

{
  "mcpServers": {
    "cpe": {
      "command": "uv",
      "args": [
        "--directory", "/absolute/path/to/classic",
        "run", "--extra", "mcp", "cpe", "mcp",
        "/absolute/path/to/texts",
        "--enable-online", "itkc",
        "--itkc-log", "/absolute/path/to/itkc-requests.jsonl",
        "--read-root", "/absolute/path/to",
        "--write-root", "/absolute/path/to/output"
      ]
    }
  }
}

Tham số khởi động và ranh giới quyền

Tham sốPhạm vi cho phépĐiều không được cấp
--allow-source-text SOURCECó thể lặp lại (không có giá trị all): local–local4, 19 mã nguồn trực tuyến, docusky:DATABASE, import:PROVIDER.Không phải giấy phép bản quyền, cam kết không lưu dữ liệu hay chứng nhận chạy mô hình cục bộ.
--enable-online SOURCECho phép kết nối nguồn trực tuyến (all, docusky:DATABASE hoặc 19 mã trực tuyến).Không cho phép trả về đoạn trích nếu thiếu --allow-source-text tương ứng.
--enable-import PROVIDERCho phép dùng trình nhập và xem siêu dữ liệu xem trước/tiến độ.Không trả về văn bản đơn vị thô nếu thiếu import:PROVIDER.
--read-root / --write-rootGiới hạn thư mục đọc/ghi hợp lệ (từ chối symlink và junction vượt ra ngoài gốc).Quyền truy cập đường dẫn không đồng nghĩa quyền tiết lộ văn bản gốc.

20 công cụ có cấu trúc thuộc 5 nhóm

Mọi công cụ đều giữ nguyên nhãn phạm vi bằng chứng, giới hạn tần suất truy vấn và ngân sách phiên của CPE (giới hạn trang 256 KiB, lưu tối đa 8 snapshot / 64 MiB).

Không gian làm việc & khám phá (6)

get_workspace, list_sources, get_source_details, get_source_catalog, configure_workspace, manage_library.

Tìm kiếm cốt lõi (4)

search_pattern (cặp/đơn), search_sources (tối đa 4 khung), search_dsl (Mẫu DSL cục bộ), itkc_search (từng bước GO_AA → MO_AA → KP_AA).

Điều hướng snapshot & phiên (3)

get_search_results (phân trang bằng con trỏ không truy vấn lại), reorder_search, manage_searches.

Nhập & xử lý văn bản (5)

get_import_catalog, import_local_release, import_remote_release, preview_import, manage_import.

Xuất dữ liệu nghiên cứu (2)

run_cli_export (CSV, JSONL chuẩn và .run.json) và export_search_snapshot (xuất snapshot tuân thủ quyền tiết lộ).

Phạm vi phát hành và giới hạn hệ sinh thái

Máy chủ MCP là chương trình dòng lệnh stdio cục bộ và mô-đun Python—không phải gói PyPI, gói MCPB hay mục đăng ký trong Model Context Protocol Registry chính thức. Kiểm thử tự động dùng dữ liệu giả lập để xác minh giao thức và không cam kết chứng nhận trên mọi ứng dụng AI thương mại, macOS hoặc Linux.

Việc cấp quyền hiển thị văn bản gốc thuộc trách nhiệm người vận hành sau khi xem xét tác phẩm, ấn bản và điều khoản nguồn. Luôn coi văn bản Hán văn trả về là dữ liệu nghiên cứu, không phải chỉ thị thực thi cho mô hình.

Tài liệu kỹ thuật chi tiết trên GitHub: docs/mcp.md · docs/mcp-data-policy.md · docs/mcp-parity.md
