連携する漢文データベースとローカルテキスト取込

Classic Pattern Explorer v3.3 は、5つの地域にわたる19のオンライン資料源への検索連携と、手元の UTF-8 テキストフォルダー・変換済みまとめファイル（.texts.jsonl）のオフライン全文検索を提供します。

注記：Classic Pattern Explorer v3.3 は、デジタル延喜式（公式ブラウザー検索・CC BY 4.0）および東京大学史料編纂所 SHIPS 7種選択機能を含む19のオンライン資料源に対応しています。

日本（5つのオンライン資料源）

NDL Lab のOCRテキスト、大蔵経行番号検索、史料編纂所古記録・文書DB、デジタル延喜式、漢詩書誌に対応します。

国立国会図書館 (NDL)

OCR抜粋・2文字以上・先頭50冊

NDL Lab 古典籍OCR本文を検索します（2文字以上の語句が必要）。句読点やOCR誤認識を含む場合があるため、引用前にタイトルリンクから紙面画像を確認してください。

SAT大正新脩大藏經テキストデータベース

先頭30件（行単位）・単一語句

大正新脩大蔵経の巻・頁・行範囲とKWIC抜粋を取得します。画像文字は □ で表示されます。CBETA と本文が重なりますが、行参照の確認に適しています。

東京大学史料編纂所 SHIPS・公式検索

7データベース選択・公式検索リンク

古記録（w16）・大日本史料（w61）・古文書（w10）・奈良（w08）・平安（w09）・鎌倉（w11）・南北朝（w29）から選び、空白なしの語句で公式検索画面を開きます（CPE内での結果取得は行いません）。

デジタル延喜式（国立歴史民俗博物館）・公式検索

v3.3追加・公式検索リンク・CC BY 4.0

空白なしの1キーワードで公式検索ページを開きます。提供元ページ側でブラウザ内フィルタリングが行われ、CPE は行や件数を取得しません。

CanD 中国・日本漢詩 · 書誌参照

先頭20件の見出し・最大10文字

異体字展開OFFで10文字以内の語句を送り、先頭20件の書誌見出し・著者・版面概要リンクのみを表示します（詩本文や訓読文は破棄）。

韓国（8つのオンライン資料源）

韓国古典総合DB、朝鮮王朝実録、奎章閣古文書、木簡判読文などの公開資料源です。

韓国古典総合DB (ITKC)

古典原文 GO_AA・韓国文集総刊 MO_AA・韓国古典総刊 KP_AA

各コレクション先頭100件までを確認し、ヒット前後約150文字の抜粋と記録リンクを表示します。現代語訳集合 IT_AA は検索対象外で、自動保存も行いません。

東洋古典総合DB (サイバー書堂)

最大50件・Open API

Open API によりタイトル・解説・リンクを取得します。本文全文や原文・訳文の層別が保証されない場合があるため、候補参照として確認してください。

韓国史データベース（国史編纂委員会）

1ページ目最大20件・単一語句

時代とDB項目を指定し、空白や引用符を含まない語句で原文タブの先頭20件（抜粋と /id/ リンク）を取得します。

朝鮮王朝実録、国史編纂委員会検索

1ページ目最大50件・単一語句

公開実録検索の原文タブに単一語句を送り、先頭50件の抜粋と記事リンクを表示します。ページ送りや全件取得は行いません。

東北アジア歴史財団 東北アジア歴史ネット検索

21史料集から1件選択・先頭20件

選択した史料集に対し、単一語句で原文1ページ目の最大20件を取得します。

NRICH 木簡（韓国）

セッション内最大600件・単一語句

公開木簡釈文（漢字・吏読・不確定記号を保持）を最大600件読み込み、連続文字列の完全一致候補を照合します。

韓国学中央研究院 古文書資料館

1ページ目最大20件・CC BY-NC-ND 2.0 KR

原文グループ（anciTXT）の先頭20件から題名・判読抜粋・日付・UCIリンクを取得します。個人・非営利の研究用途に限られます。

奎章閣古文書 · 原文検索

先頭20件・抜粋最大600文字

ソウル大学校奎章閣 GMS 文書群に対し空白なし80文字以内で検索し、書誌情報・インライン抜粋・公式ビューアーリンクを表示します。

台湾（4つのオンライン資料源）

漢文大蔵経、DocuSky 公開データベース、台湾史料全文、古契書を収録します。

CBETA 漢文大蔵経

前後各約40文字・先頭50巻・CC BY-NC-SA 4.0

CBData API からヒット前後約40文字（割注除く）を取得し、複合条件を照合して CBETA Online の該当巻へリンクします。

DocuSky · 佛寺志靈應故事ほか精査済み29プロファイル

1頁50件・手動最大5頁

一度に1つの公開データベースを検索します（佛寺志靈應故事・承政院日記・朝鮮王朝實錄・大明一統志など精査済み29件と未精査DBを区別して表示）。

中央研究院台湾史研究所 台湾文献全文データベース

1ページ目最大20件・単一語句

空白なしの単一語句で検索し、先頭20件の題名・抜粋・出典リンクを取得します。

台湾歴史デジタル図書館 · 古契書

先頭10件・最大600文字

THDL 古契書コレクションを空白なし1キーワードで検索し、先頭10件の抜粋と公式文書リンクを表示します。

中国（1つのオンライン資料源）

歴代石刻墓誌の録文索引を検索します。

浙江大学中国歴代墓誌DB · 録文検索

既定7コレクション・先頭15件

空白なし1キーワードで録文フィールドを検索し、先頭15件の題名・時代・種別・記録リンクを表示します（本文抜粋は返されません）。

ベトナム（1つのオンライン資料源）

漢喃文書のOCRコーパスを検索します。

Việt Điện 漢喃OCRコーパス

1ページ目最大20件・単一語句

Digitizing Vietnam の公開OCR検索から先頭20件の抜粋とページ画像リンクを取得します。機械OCRの誤認識や異体字展開が含まれるため、原版画像を確認してください。

手元のテキストとローカル取込機能

4つの独立したフォルダー枠（local–local4）に登録した UTF-8 .txt・.md および .texts.jsonl 形式はオフラインで全文検索できます。

  • 韓国公共データポータル XML/ZIP：国史編纂委員会（三国史記・高麗史・朝鮮王朝実録太祖〜哲宗など）、韓国古典翻訳院、韓国学中央研究院蔵書閣登録、東北アジア歴史財団資料を一括または個別に取り込めます。
  • Chinese Text Project（CTP/CText）：提供元が許可する範囲で単一章はAPIキーなしで試用でき、作品全体の章一覧には各自の CTP API キーが必要です。
  • 部分取込・作品ファインダー：MPIWG 希少地方志（1プレビューあたり最大50単位）、CBETA P5 XML、NDL OCR ページ、プロジェクト・グーテンベルク、作品別対応DB検索ガイド。
  • 書誌サイドカー（.manifest.toml）：NAME.txt.manifest.toml を同じ場所に置くと title・edition・era・year・year_end を年代順ソートに利用できます。

検索範囲と出典上の注意

Classic Pattern Explorer は連携先の各機関・データベースとは無関係の個人プロジェクト（MIT ライセンス）であり、本文コーパスや現代語訳・API生応答を同梱して配布しません。

オンライン検索は各提供元の件数上限内で返された抜粋または書誌参照のみを扱い、全件クローリングは行いません。結果が0件であっても歴史的コーパスに存在しない証明にはなりません。
