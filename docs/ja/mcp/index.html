AI 研究ワークフロー向けローカル stdio MCP サーバー

公式 Python MCP SDK v2 を用いてローカルの stdin/stdout 上で20の研究ツールを提供し、原文テキストの返却を起動時の明示的な許可フラグで制御します。

既定では参照情報とメタデータのみ（text_withheld: true）を返します。本文や抜粋を返すには対象ごとの --allow-source-text 指定が必要です。

導入と事前チェックコマンド

Python 3.11 以上と uv を用意して mcp オプション依存関係を導入し、ホスト接続前にローカル確認フラグで検証できます（Windows の cpe-mcp.exe も同じ引数を受け付けます）。

uv sync --extra mcp
uv run --extra mcp cpe mcp --version
uv run --extra mcp cpe mcp path/to/texts --doctor --json
uv run --extra mcp cpe mcp path/to/texts --enable-online itkc --itkc-log itkc-requests.jsonl --print-config
uv run --extra mcp cpe mcp path/to/texts --allow-source-text local

クライアント設定テンプレート（既定・参照専用）

stdio 対応 MCP ホストの設定例です。--allow-source-text を付けない限り、識別子・タイトル・URL・メタデータのみが返り、原文抜粋と正規レコードは抑制されます。

{
  "mcpServers": {
    "cpe": {
      "command": "uv",
      "args": [
        "--directory", "/absolute/path/to/classic",
        "run", "--extra", "mcp", "cpe", "mcp",
        "/absolute/path/to/texts",
        "--enable-online", "itkc",
        "--itkc-log", "/absolute/path/to/itkc-requests.jsonl",
        "--read-root", "/absolute/path/to",
        "--write-root", "/absolute/path/to/output"
      ]
    }
  }
}

起動フラグと権限の境界

起動引数許可される操作許可されない範囲
--allow-source-text SOURCE反復指定可（all は不可）：local–local4、19のオンラインID、docusky:DATABASE、import:PROVIDER。提供元の利用許諾、モデル側の非保存保証、ローカル実行の証明にはなりません。
--enable-online SOURCEオンライン資料源への問い合わせ許可（all、docusky:DATABASE、19のオンラインID）。本文・抜粋の開示権限は含まないため --allow-source-text が別途必要です。
--enable-import PROVIDER取込プロバイダーの利用とプレビュー／進捗メタデータの取得。import:PROVIDER 指定なしでは単位生テキストを返しません。
--read-root / --write-root読み書き可能なルートディレクトリの制限（ルート外のシンボリックリンク・ジャンクションを拒否）。パス権限だけでは原文テキストは開示されません。

5カテゴリー・20の構造化ツール

各ツールは CPE の証拠範囲ラベル、リクエスト間隔制限、セッション予算（応答 256 KiB、スナップショット 8件・64 MiB）を引き継ぎます。

作業領域・探索（6）

get_workspace、list_sources、get_source_details、get_source_catalog、configure_workspace、manage_library。

基本検索（4）

search_pattern（複合・単一）、search_sources（最大4パネル）、search_dsl（ローカルパターンDSL）、itkc_search（GO_AA → MO_AA → KP_AA 段階検索）。

スナップショット操作（3）

get_search_results（再照会なしのカーソルページング）、reorder_search、manage_searches。

テキスト取込（5）

get_import_catalog、import_local_release、import_remote_release、preview_import、manage_import。

研究データ出力（2）

run_cli_export（正規 CSV・JSONL・.run.json）および export_search_snapshot（開示設定に従うスナップショット出力）。

公開範囲とエコシステムの境界

本 MCP サーバーはローカル stdio バイナリおよび Python モジュールであり、PyPI パッケージ、MCPB バンドル、公式 Model Context Protocol Registry の登録物ではありません。自動テストはモックを用いてプロトコル契約を検証しており、商用 AI デスクトップクライアントや macOS・Linux 全般での認証を保証するものではありません。

原文開示の許可は、対象著作物・版・提供元規約を確認したホスト側の判断です。返却された漢文テキストは常に研究データとして扱い、プロンプト指示として解釈しないでください。
