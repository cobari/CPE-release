漢文の原文から文型の候補を探す

Classic Pattern Explorer は、漢文（Literary Sinitic）の原文から 以…爲 や 雖…而 のような文型の候補を探すデジタル・ヒューマニティーズ（人文情報学）の研究支援ツールです。候補ごとにテキストや資料源の抜粋が含む文脈を示し、出典リンクがあればそれも添えて、研究者が自ら読んで判断できるよう支援します。

Windows 版をダウンロードcpe-gui.exe、64 ビット
v2.0 の全ダウンロードmacOS・Linux 用ソースパッケージ 利用案内を読む詳細ドキュメント (README)

主な機能

文脈の中の候補

資料から得られた文脈を候補と一緒に表示します。返された本文で確認できない結果は「未確認」と表示します。出典リンクがある場合は、元の資料も確認できます。

5つの画面言語

日本語、韓国語、中国語簡体字・繁体字、英語。画面言語を切り替えても原文は変換されたり変わりません。（ウェブサイトの案内はベトナム語を含む6言語で提供しています。）

構文解析器ではなく研究支援ツール

複合検索では候補を構造的な手がかりに基づいて可能性の高い結果と低い結果に分けて提示するだけであり、文脈の判断は利用者に委ねられます。

検索対象

手元のテキスト

手元のコンピュータの全文テキスト

選択したフォルダ内の UTF-8 .txt・.md ファイルと、機関の原典を変換して保存した .texts.jsonl バンドルファイル。各ファイルの全文を検索します。

  • 韓国の公共データポータルが提供する国史編纂委員会・韓国古典翻訳院・韓国学中央研究院の原典資料をダウンロードし、検索可能なテキストバンドルとして保存します。
  • Chinese Text Project（CTP/CText, ctext.org）：単一の章はキーなしで取得を試せます。作品全体の章一覧には各自の CTP API キーが必要で、利用可能範囲は CTP の定めに従います。
  • MPIWG の稀覯地方志から選択した一部、対応するプロジェクト・グーテンベルクおよび NDL 資料、CBETA や国史編纂委員会の XML ファイルも取り込めます。
  • 自分で用意したプレーンテキストファイル。

オンライン資料検索

提供機関が返した語句・資料情報、要インターネット

資料源に検索語を送信し、そこから返されたテキストを確認します。

  • 韓国古典総合DB（ITKC）：原文コレクションである古典原文および韓国文集叢刊（約150字抜粋）。朝鮮王朝実録などの翻訳コレクションは検索しません。
  • 国立国会図書館（NDL）：古典籍の OCR テキスト。検索要素のうち少なくとも1つは2文字以上が必要です。
  • CBETA 電子仏典：検索語の前後約40字ずつ抜粋。
  • 東洋古典総合DB：語句や資料情報、出典リンクを表示します。返されたテキストで検索条件を確認できない資料は未確認候補として区分します。
  • DocuSky：佛寺志靈應故事 のうち 普陀洛迦新志靈應故事 と 清涼山志靈應故事 から選ばれた故事に限り検索し、書籍全体ではありません。

知っておくべき制限

  • オンライン検索は各資料源が返した語句と資料情報の範囲内で行われます。結果件数の上限は資料源ごとに異なります。
  • 結果が出ないからといって、その文型が使われていないという意味ではありません。
  • NDL の OCR テキストには誤認識が含まれる場合があるため、引用する前に紙面の画像を確認してください。
  • MPIWG は選択した節から一度に最大50単位のうち対応する部分のみを取り込んで手元で検索します。この単位は書籍のページ番号とは異なり、全資料のオンライン検索は提供していません。
  • 用例を引用する前には、表示される出典リンクを開いて全体の原文と文脈を確認してください。
  • 資料源サーバへの負荷を考慮してリクエスト間隔と回数を制限しています。ダウンロードした資料には各提供機関の利用条件が適用されます。

利用開始

Windows

v2.0 リリースから cpe-gui.exe をダウンロードしてダブルクリックするだけです。Python は不要です。Microsoft Edge WebView2 ランタイムで動作するため、ウィンドウが開かない場合はランタイムをインストールしてください。

macOS および Linux

v2.0 リリースからソースパッケージをダウンロード・解凍し、cpe-gui.command（macOS）または cpe-gui.sh（Linux）を実行します。初回実行時に同意すると uv をインストールし、Python 環境をダウンロードするためインターネット接続が必要です。

コマンドライン

ソースパッケージには CSV、JSONL および実行記録を保存する cpe コマンドも含まれています。詳細は利用案内をご覧ください。
