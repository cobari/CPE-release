漢文の原文から文型の候補を探す

Classic Pattern Explorer は、漢文（Literary Sinitic）の原文から 以…爲 や 雖…而 のような文型の候補を探すデジタル・ヒューマニティーズ（人文情報学）の研究支援ツールです。候補ごとに、テキストや資料源の抜粋から得られる文脈を示し、出典リンクがあればそれも添えて、研究者が自ら読んで判断できるよう支援します。

Windows 版をダウンロードcpe-gui.exe、64 ビット
v3.0.0 のダウンロード一覧macOS・Linux 用ソースパッケージ 利用案内を読む詳細ドキュメント (README)

v3.0.0 リリース案内： Windows では単体実行ファイル cpe-gui.exe を直接実行できます（Edge WebView2 ランタイムが必要）。macOS・Linux はソースパッケージから実行します（初回起動時にランタイムをダウンロード、インターネット接続が必要）。5地域18のオンライン資料源とローカルテキストフォルダを検索できます。

プログラム画面の例

導入と最初の検索手順

Windows

v3.0.0 リリースから cpe-gui.exe をダウンロードしてダブルクリックします。Python は不要です。Microsoft Edge WebView2 ランタイムで動作するため、ウィンドウが開かない場合はランタイムをインストールしてください。

macOS および Linux

v3.0.0 リリースからソースパッケージをダウンロード・解凍し、cpe-gui.command（macOS）または cpe-gui.sh（Linux）を実行します。初回実行時に uv の導入確認を行い、Python 環境と依存関係を自動取得するためインターネット接続が必要です。

コマンドライン

ソースパッケージには CSV、JSONL および実行記録を保存する cpe コマンドも含まれています。詳細は利用案内をご覧ください。

最初の検索手順

1. 資料源の選択

「検索ソース」でテキストフォルダを追加するか、オンライン資料源を選びます。フォルダとオンライン資料源を合わせて最大4つまで選択できます。

2. 検索語の入力

「検索」で単語や語句を探すには単一検索を選びます。使用できる検索式は資料源によって異なります。第1要素の後に第2要素が現れる箇所を探すには複合検索を選びます。

3. 文脈の照合と確認

返された結果や書誌情報を確認し、出典リンクがある場合は原文の文脈を照合してください。複合検索では、A・Bの原文や構造的な手がかりによる分類が表示される場合に、合わせて検討してください。

主な機能

文脈の中の候補

資料から得られた文脈で候補を確認します。原文で確認できない結果は未確認として表示します。出典リンクがある場合は、原文全体も照合できます。

6つの表示言語

日本語、韓国語、簡体字中国語、繁体字中国語、ベトナム語、英語。表示言語を切り替えても、原文のテキストが変換されたり変更されたりすることはありません。

構文解析器ではなく研究支援ツール

複合検索では候補を構造的な手がかりに基づいて可能性の高い結果と低い結果に分けて提示するだけであり、文脈の判断は利用者に委ねられます。

検索対象

手元のファイル: 指定した UTF-8 テキストや取り込んだテキスト集（.texts.jsonl）の全文をオフラインで直接検索します。
オンライン資料検索: 18のオンライン資料源に接続します。抜粋・書誌情報の取得、または公式検索画面への移動など、接続先によって動作が異なります。提供元の件数制限に従い、資料群全体の取得や全文クロールは行いません。

手元のテキスト

手元のコンピュータの全文テキスト

選択したフォルダー内の UTF-8 .txt・.md ファイルと、機関の原典を変換して保存した .texts.jsonl 形式のテキストバンドル。各ファイルの全文を検索します。

  • 韓国の公共データポータルが提供する国史編纂委員会・韓国古典翻訳院・韓国学中央研究院の原典資料をダウンロードし、検索可能なテキストバンドルとして保存します。
  • Chinese Text Project（CTP/CText, ctext.org）：単一の章はキーなしで取得を試せます。作品全体の章一覧には各自の CTP API キーが必要で、利用可能範囲は CTP の定めに従います。
  • MPIWG の稀少地方志から選択した一部、対応しているプロジェクト・グーテンベルクおよび NDL 資料、CBETA や国史編纂委員会の XML ファイルも取り込めます。
  • 自分で用意したプレーンテキストファイル。

オンライン資料検索

18の資料源からの抜粋・書誌情報、インターネット接続が必要

検索先にキーワードを送り、提供されたテキストや書誌情報を確認します。5つの地域別に整理されています。

  • 韓国（8）： 韓国古典総合DB (ITKC)、東洋古典総合DB (サイバー書堂)、韓国史データベース（国史編纂委員会）、朝鮮王朝実録、国史編纂委員会検索、東北アジア歴史財団 東北アジア歴史ネット検索、NRICH 木簡（韓国）、韓国学中央研究院 古文書資料館、奎章閣古文書 · 原文検索。
  • 日本（4）： 国立国会図書館 (NDL)、SAT大正新脩大藏經テキストデータベース、東京大学古記録全文DB · 公式検索画面、CanD 中国・日本漢詩 · 書誌参照。
  • 中国（1）： 浙江大学中国歴代墓誌DB · 録文検索。
  • 台湾（4）： CBETA 漢文大蔵経、DocuSky · 佛寺志靈應故事、中央研究院台湾史研究所 台湾文献全文データベース、台湾歴史デジタル図書館 · 古契書。
  • ベトナム（1）： Việt Điện 漢喃OCRコーパス。

結果の解釈と利用案内

結果を解釈する際の注意点

  • 結果が出ないからといって、その文型が使われていないという意味ではありません。
  • 複合検索の候補分類は検討を助ける構造的な手がかりであり、文法的な解釈を確定するものではありません。
  • 用例を引用する前には、表示される出典リンクを開いて全体の原文と文脈を確認してください。
  • NDL および Việt Điển の OCR テキストには誤認識が含まれる場合があるため、引用する前に紙面の画像を確認してください。

資料の利用と提供条件

  • オンライン検索では提供元の制限に応じた抜粋や書誌情報のみを取得し、全件ダウンロードやクローリングは行いません。
  • オンライン検索は各資料源が返した語句と資料情報の範囲内で行われます。結果件数の上限は資料源ごとに異なります。
  • MPIWG のプレビューでは、選択した節から最大50の原本単位を読み込みます。この単位は書籍のページ番号とは異なり、全資料のオンライン検索は提供していません。対応している部分は手元に保存して検索できます。
  • 資料源サーバーの負荷を軽減するため、リクエストの間隔と回数を制限しています。ダウンロードした資料には各提供機関の利用条件が適用されます。
