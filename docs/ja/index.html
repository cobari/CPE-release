漢文の原文から文型の候補を探す

Classic Pattern Explorer は、漢文（Literary Sinitic）の原文から 以…爲 や 雖…而 のような文型の候補を探すデジタル・ヒューマニティーズ（人文情報学）の研究支援ツールです。候補ごとにテキストや資料源の抜粋が含む文脈を示し、出典リンクがあればそれも添えて、研究者が自ら読んで判断できるよう支援します。

Windows 版をダウンロードcpe-gui.exe、64 ビット v2.0 の全ダウンロード 利用案内を読む

主な機能

  • 文脈の中の候補

    候補を、提供された本文や抜粋の文脈とともに表示します。返されたテキストでは確認できない資料は未確認候補として区別し、出典リンクがあれば添えます。

  • 5つの画面言語

    韓国語、日本語、簡体字中国語、繁体字中国語、英語に対応。言語を切り替えても原文が変換されたり変更されたりすることはありません。

  • 構文解析器ではなく研究支援ツール

    複合検索では構造的な手がかりにより候補を2つのグループに分けて提示します。この区分は文法判定ではなく、判断は研究者に委ねられます。

検索対象

自分のテキスト

PC内の全文テキスト

指定したフォルダーの UTF-8 .txt・.md ファイル、および機関原文を変換保存した .texts.jsonl バンドルファイルを検索します。各ファイルの全文を対象に検索が行われます。

  • 韓国の公共データポータルで対応している国史編纂委員会・韓国古典翻訳院・韓国学中央研究院の原文資料を、検索できるテキストのまとまりとして保存します。
  • Chinese Text Project（CTP/CText、ctext.org）：CTPが許可する単独の章はキーなしで取得を試せます。作品全体の章一覧には、ご自身のCTP APIキーが必要です。
  • MPIWG稀見地方志の選択部分、対応するProject Gutenberg・NDL資料、CBETA・国史編纂委員会のXMLファイルも取り込めます。
  • 自身で用意した任意のプレーンテキストファイル。

オンライン資料の検索

返された本文・資料情報、インターネット接続が必要

対応する資料源へ検索語を送り、返されたテキストを確認します。

  • 韓国古典総合DB（ITKC）：古典原文・韓国文集叢刊（約150字抜粋）。朝鮮王朝実録などの翻訳コレクションは対象外です。
  • 国立国会図書館（NDL）：古典籍のOCRテキスト。検索要素の少なくとも一つは2文字以上である必要があります。
  • CBETA 中華電子仏典協会：大蔵経原文から検索語の前後に約40文字ずつの抜粋を取得。
  • 東洋古典総合DB：本文の一部や資料情報、出典リンクを表示します。返されたテキストでは検索条件を確認できない資料は、未確認候補として区別します。
  • DocuSky：佛寺志靈應故事のうち、普陀洛迦新志靈應故事と清涼山志靈應故事の2資料に限って検索します。

留意すべき制限事項

  • オンライン検索の範囲は、資料源から返された本文や資料情報に限られます。結果件数の上限は資料源ごとに異なります。
  • 結果がなくても、その文型が使われていないことの証明にはなりません。
  • NDLのOCRテキストには認識誤りがあり得るため、引用前に書頁画像を確認してください。
  • MPIWGは、選択した節から一度に最大50件の内容単位のうち対応する部分を取り込み、手元のパソコンで検索します。この単位は印刷本のページ番号とは異なり、資料全体のオンライン検索には対応していません。
  • 用例を引用する前に、出典リンクがあれば開き、原文全体と文脈を確認してください。
  • 提供元のサーバーに配慮し、要求の間隔と回数を制限しています。取得した資料には各提供元の利用条件が適用されます。

はじめ方

Windows

v2.0 リリースから cpe-gui.exe をダウンロードしてダブルクリックするだけです。Python は不要です。Microsoft Edge WebView2 ランタイムで動作するため、起動しない場合はランタイムをインストールしてください。

macOS と Linux

v2.0 リリースからソースパッケージをダウンロードして解凍し、cpe-gui.command（macOS）または cpe-gui.sh（Linux）を実行します。初回の確認で uv のインストールと Python 環境の取得を行うため、インターネット接続が必要です。

コマンドライン

ソースパッケージには CSV・JSONL や実行記録を出力する cpe コマンドも含まれています。詳細は利用案内をご覧ください。
