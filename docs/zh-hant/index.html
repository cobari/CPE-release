在文言文原文中查找句式候選

Classic Pattern Explorer 是一款面向數位人文（Digital Humanities）研究的輔助工具，用於在文言文（漢文，Literary Sinitic）原文中查找 以…爲、雖…而 等句式候選用例。每個用例均顯示文字或資料來源摘錄所包含的前後文，並在可用時附帶出處連結，供研究者親自閱讀與研判。

下載 Windows 版cpe-gui.exe，64 位元
v2.0 全部下載macOS 與 Linux 原始碼套件 閱讀使用說明詳細說明書 (README)

目前公開發布的 v2.0 版本尚未包含越南語。

主要功能

前後文中的用例

在提供的上下文脈絡中檢視句式候選。在原文中無法核對的結果標為未核實。包含出處連結時，亦可對照完整原文。

六種介面語言

繁體中文、簡體中文、韓語、日語、越南語與英語。切換介面語言絕不會轉換或變更原文用字。

研究輔助工具而非語法分析器

在複合檢索中，僅依據文獻結構線索將候選用例分為可能性較高與較低的結果，前後文的判斷由研究者自行把握。

檢索範圍

本機文字

本機電腦中的全文檢索

所選目錄中的 UTF-8 .txt、.md 檔案，以及程式轉換儲存的機構古籍 .texts.jsonl 封裝檔案。檢索每個檔案的完整文字。

  • 從韓國公共資料入口網站下載國史編纂委員會、韓國古典翻譯院、韓國學中央研究院的古籍資料，儲存為可檢索的文字封裝檔案。
  • Chinese Text Project（CTP/CText, ctext.org）：單一章節可在 CTP 允許的情況下無需金鑰嘗試取得；整部著作的章節清單需要自備 CTP API 金鑰，實際可用範圍由 CTP 決定。
  • MPIWG 珍本地方志中所選的部分章節、支援的古騰堡計畫及 NDL 資料、CBETA 與國史編纂委員會 XML 檔案。
  • 自行準備的純文字檔案。

線上資料來源檢索

機構返回的文句與資料資訊，需網路連線

向資料來源發送檢索詞，核對返回的文字。

  • 韓國古典綜合DB（ITKC）：原文文獻庫（古典原文與韓國文集叢刊，摘錄約150字）。不檢索朝鮮王朝實錄等翻譯庫。
  • 日本國立國會圖書館（NDL）：古籍 OCR 文字。檢索要素中至少有一項須為兩個漢字以上。
  • CBETA 電子佛典：檢索詞前後約40字摘錄。
  • 東洋古典綜合DB：提供文句或資料資訊及出處連結。返回文字中未核實檢索條件者標為未核實候選。
  • DocuSky：僅檢索 佛寺志靈應故事 資料庫中 普陀洛迦新志靈應故事 與 清涼山志靈應故事 的故事選段，並非全書。

解讀檢索結果時的注意事項

  • 檢索無結果並不代表該句式未曾使用。
  • 引用用例前，請打開提供的出處連結確認完整原文與上下文。
  • NDL 的 OCR 文字可能存在辨識誤差，引用前請核對原書圖像底本。

資料利用與使用條件

  • 線上檢索受各資料來源返回之文句與資料資訊範圍限制，且存在單次檢索結果上限。
  • MPIWG 僅從所選節中一次擷取最多50個單位中受支援的部分存入本機進行檢索。這些單位並不對應紙本實體書籍的頁碼；不提供整部語料庫的線上檢索。
  • 為減輕資料來源伺服器負擔，程式限制了請求間隔與頻次。下載的資料受各機構使用條款約束。

快速開始

Windows

從 v2.0 發布頁面下載 cpe-gui.exe 點擊兩下執行即可，無需安裝 Python。基於 Microsoft Edge WebView2 執行階段 運作；若視窗未開啟請安裝該執行階段。

macOS 與 Linux

從 v2.0 發布頁面下載原始碼套件並解壓縮，執行 cpe-gui.command (macOS) 或 cpe-gui.sh (Linux)。首次執行時若同意將安裝 uv 並下載 Python 環境，因此需要網路連線。

命令列

原始碼套件內亦包含可輸出 CSV、JSONL 及執行紀錄的 cpe 命令工具。詳情請參閱 使用說明。
