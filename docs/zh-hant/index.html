在文言文原文中查找句式候選

Classic Pattern Explorer 是一款面向數位人文（Digital Humanities）研究的輔助工具，用於在文言文（漢文，Literary Sinitic）原文中查找 以…爲、雖…而 等句式候選用例。每個用例均顯示文字或資料來源摘錄所包含的前後文，並在可用時附帶出處連結，供研究者親自閱讀與研判。

下載 Windows 版cpe-gui.exe，64 位元 v2.0 全部下載 閱讀使用說明

主要功能

  • 前後文中的候選

    在提供的正文或摘錄範圍內顯示候選用例的前後文。無法在回傳文字中確認的資料會標示為未確認候選；有出處連結時一併提供。

  • 五種介面語言

    支援韓語、日語、簡體中文、繁體中文與英語。切換介面語言絕不會轉換或變更文獻原文。

  • 研究輔助工具而非句法分析器

    在組合檢索中，程式依據結構線索將候選用例分為兩組呈現。這種分組並非語法判定，最終理解仍由研究者掌握。

檢索範圍

自己的文本

本機檔案全文

檢索所選資料夾中的 UTF-8 .txt、.md 文字檔，以及轉換儲存的機構原文 .texts.jsonl 合集檔案。檢索涵蓋各檔案的全部文字內容。

  • 支援從韓國公共資料入口網取得國史編纂委員會、韓國古典翻譯院及韓國學中央研究院的指定原文資料，並儲存為可檢索的文字合集。
  • 中國哲學書電子化計劃（CTP/CText，ctext.org）：對於CTP允許的單一章節，可嘗試不使用金鑰取得；整部作品的章節列表需要您自己的CTP API金鑰。
  • 亦可匯入MPIWG稀見地方志的選定部分、支援的古騰堡計劃及NDL資料，以及CBETA和國史編纂委員會的XML檔案。
  • 研究者自行整理的各類純文字檔案。

線上資料檢索

回傳的文段與資料資訊，需網路連線

將檢索詞傳送至支援的資料來源，再核對回傳的文字。

  • 韓國古典綜合DB（ITKC）：古典原文與韓國文集叢刊（約150字摘錄）。不檢索朝鮮王朝實錄等現代翻譯集合。
  • 日本國立國會圖書館（NDL）：古籍OCR文字；至少一個檢索要素須為兩個或更多字元。
  • CBETA 中華電子佛典協會：從大藏經原文中提取檢索詞前後約40字的用例摘錄。
  • 東洋古典綜合DB：顯示回傳的文段、資料資訊及出處連結。無法在回傳文字中核實檢索條件的資料會標示為未確認候選。
  • DocuSky：僅檢索佛寺志靈應故事中的普陀洛迦新志靈應故事與清涼山志靈應故事兩項資料。

需注意的使用局限

  • 線上檢索限於各資料來源回傳的文段與資料資訊；結果數量上限因資料來源而異。
  • 沒有結果並不能證明該句式從未出現。
  • NDL的OCR文字可能含有辨識錯誤，引用前請核對書頁影像。
  • MPIWG每次從選定章節的最多50個內容單元中匯入支援的部分，供本機檢索。這些單元並非印刷書頁編號，亦不提供整庫線上檢索。
  • 引用用例前，如有出處連結，請開啟並核對完整原文與前後文。
  • 為減輕提供方伺服器負擔，程式設有請求間隔及次數上限。下載資料須遵守各提供方的使用條件。

開始使用

Windows

從 v2.0 發行版下載 cpe-gui.exe 並按兩下即可執行，無需 Python。Microsoft Edge WebView2 執行階段為執行基礎；若視窗未開啟，請安裝該執行階段。

macOS 與 Linux

從 v2.0 發行版下載原始碼套件，解壓縮後執行 cpe-gui.command（macOS）或 cpe-gui.sh（Linux）。初次執行時若同意則會自動安裝 uv 並下載 Python 環境，需要網路連線。

命令列

原始碼套件中亦包含可輸出 CSV、JSONL 及執行記錄的 cpe 命令。詳情請參閱使用說明。
