從漢文原文中尋找句式候選用例

Classic Pattern Explorer 是為數位人文研究設計的輔助工具，可從漢文（Literary Sinitic）原文中尋找 以…爲、雖…而 等句式候選用例。研究者可在提供的原文或摘錄中檢視候選用例的前後文，並透過出處連結進一步對照原始資料，自行判斷句式是否成立。

下載 Windows 版cpe-gui.exe，64 位元
v3.0.0 下載清單macOS 與 Linux 原始碼套件 閱讀使用說明詳細說明書 (README)

v3.0.0 發行說明： Windows 使用者可直接執行獨立的 cpe-gui.exe（需 Microsoft Edge WebView2 執行階段）。macOS 與 Linux 使用者請下載原始碼套件並執行 cpe-gui.command 或 cpe-gui.sh（需 Python 與 uv）。檢索5個地區的18個線上資料源需要網路連線，並依各機構檢索上限傳回有限的摘錄或書目記錄。

主要功能

前後文中的用例

在提供的前後文中檢視句式候選。在原文中無法核對的結果標為未核實。包含出處連結時，亦可對照完整原文。

六種介面語言

繁體中文、簡體中文、韓語、日語、越南語與英語。切換介面語言絕不會轉換或變更原文用字。

研究輔助工具而非語法分析器

「組合檢索」依結構線索將候選用例分組，方便比較可能性較高與較低的結果。這項分組不等於語法判定，仍須結合前後文研讀。

檢索範圍

本機文字

本機電腦中的全文檢索

檢索所選資料夾中 UTF-8 .txt、.md 檔案的全文，以及程式透過支援的匯入功能儲存的 .texts.jsonl 文字集檔案。

  • 從韓國公共資料入口網站下載國史編纂委員會、韓國古典翻譯院、韓國學中央研究院的古籍資料，儲存為可檢索的文字集檔案。
  • Chinese Text Project（CTP/CText, ctext.org）：單一章節可在 CTP 允許的情況下無需金鑰嘗試取得；整部著作的章節清單需要自備 CTP API 金鑰，實際可用範圍由 CTP 決定。
  • MPIWG 稀見地方志中所選的部分章節、支援的古騰堡計畫及 NDL 資料、CBETA 與國史編纂委員會 XML 檔案。
  • 自行準備的純文字檔案。

線上資料來源檢索

18個資料源的摘錄與書目記錄，需要網路連線

向支援的線上來源發送檢索詞，查閱傳回的文句或書目資訊。依5個國家與地區分類：

  • 韓國（8）： 韓國古典綜合資料庫 (ITKC)、東洋古典綜合資料庫 (Cyber Seodang)、韓國史資料庫綜合檢索、朝鮮王朝實錄，國史編纂委員會檢索、東北亞歷史財團 東北亞歷史網檢索、NRICH 木簡釋文（韓國）、韓國學中央研究院 古文書資料館、奎章閣古文書 · 原文檢索。
  • 日本（4）： 日本國立國會圖書館 (NDL)、SAT大正新脩大藏經文本資料庫、東京大學古記錄全文DB · 官方檢索、CanD 中國與日本漢詩 · 書目參考。
  • 中國（1）： 浙江大學 CSID · 錄文檢索。
  • 臺灣（4）： CBETA 漢文佛典、DocuSky · 佛寺志靈應故事、中央研究院臺灣史研究所 臺灣文獻全文資料庫、臺灣歷史數位圖書館 · 古契書。
  • 越南（1）： Việt Điện 漢喃OCR語料庫。

解讀檢索結果時的注意事項

  • 檢索無結果並不代表該句式未曾使用。
  • 引用用例前，請開啟提供的出處連結，核對完整原文與前後文。
  • NDL 與 Việt Điển 的 OCR 文本可能存在辨識誤差，引用前請核對原書圖像底本。
  • 線上檢索僅在提供方傳回限制內取得有限摘錄或書目記錄，不執行全庫下載或全文抓取。

資料利用與使用條件

  • 線上檢索可核對的範圍取決於各來源回傳的摘錄與資料資訊，單次結果數也有上限。
  • MPIWG 方志每次預覽最多讀取所選卷目的50個來源單元，可將支援的部分儲存為本機可檢索文字。這些單位並不對應紙本書籍的頁碼；不提供整部語料庫的線上檢索。
  • 為減輕資料來源伺服器負擔，程式限制了請求間隔與頻次。下載的資料受各機構使用條款約束。

快速開始

Windows

從 v3.0.0 發布頁面下載 cpe-gui.exe，按兩下即可執行，無須安裝 Python。程式使用 Microsoft Edge WebView2 Runtime 執行；若視窗無法開啟，請安裝此執行環境。

macOS 與 Linux

從 v3.0.0 發布頁面下載原始碼套件並解壓縮，執行 cpe-gui.command (macOS) 或 cpe-gui.sh (Linux)。首次執行時若同意將安裝 uv 並下載 Python 環境，因此需要網路連線。

命令列

原始碼套件內亦包含可輸出 CSV、JSONL 及執行紀錄的 cpe 命令工具。詳情請參閱 使用說明。
