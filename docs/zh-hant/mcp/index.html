面向 AI 研究工作流程的本機 stdio MCP 伺服器

基於官方 Python MCP SDK v2，透過本機 stdin/stdout 公開 20 項研究工具，並將原文文本傳回嚴格限制於主機明確啟動授權之內。

預設模式僅傳回參照與中繼資料（text_withheld: true）。如需傳回本機文本或線上摘錄，必須於啟動參數中為對應來源明確指定 --allow-source-text。

安裝與啟動前檢查

安裝 Python 3.11+ 與 uv 並同步 mcp 選用相依套件後，可在連線用戶端前先以檢查旗標驗證本機設定（Windows 獨立執行檔 cpe-mcp.exe 支援相同參數）：

uv sync --extra mcp
uv run --extra mcp cpe mcp --version
uv run --extra mcp cpe mcp path/to/texts --doctor --json
uv run --extra mcp cpe mcp path/to/texts --enable-online itkc --itkc-log itkc-requests.jsonl --print-config
uv run --extra mcp cpe mcp path/to/texts --allow-source-text local

用戶端設定範本（預設僅傳回參照）

將以下 JSON 填入支援 stdio 的 MCP 主機設定。未設定 --allow-source-text 時，工具僅傳回識別碼、題名、連結與中繼資料，不傳回正文與標準記錄：

{
  "mcpServers": {
    "cpe": {
      "command": "uv",
      "args": [
        "--directory", "/absolute/path/to/classic",
        "run", "--extra", "mcp", "cpe", "mcp",
        "/absolute/path/to/texts",
        "--enable-online", "itkc",
        "--itkc-log", "/absolute/path/to/itkc-requests.jsonl",
        "--read-root", "/absolute/path/to",
        "--write-root", "/absolute/path/to/output"
      ]
    }
  }
}

啟動參數與權限邊界

啟動參數授予的能力未授予的範圍
--allow-source-text SOURCE可重複指定（無 all 值）：local–local4、19 個線上 ID、docusky:DATABASE、import:PROVIDER。不構成出版方授權許可、零留存保證或本機模型執行證明。
--enable-online SOURCE允許向指定線上來源發送查詢（all、docusky:DATABASE 或 19 個線上 ID）。不包含傳回原文摘錄的權限，仍須配對 --allow-source-text。
--enable-import PROVIDER允許呼叫匯入提供方並檢視預覽與進度中繼資料。未授予 import:PROVIDER 時不傳回原始單元文本。
--read-root / --write-root限定工具可讀寫的檔案系統根目錄（拒絕越界符號連結與目錄聯接）。路徑讀寫權不等於原文文本揭露授權。

5 大類共 20 項結構化工具

所有工具均遵循 CPE 的證據範圍標註、請求頻次保護與工作階段預算（單頁 256 KiB 上限，最多保留 8 個快照 / 64 MiB）。

工作區與來源探索（6）

get_workspace、list_sources、get_source_details、get_source_catalog、configure_workspace、manage_library。

核心檢索（4）

search_pattern（組合/單項）、search_sources（最多 4 面板）、search_dsl（本機模式 DSL）、itkc_search（GO_AA → MO_AA → KP_AA 分步工作階段）。

快照瀏覽與管理（3）

get_search_results（透過游標翻頁而不重複查詢來源）、reorder_search、manage_searches。

文本匯入與擷取（5）

get_import_catalog、import_local_release、import_remote_release、preview_import、manage_import。

研究資料匯出（2）

run_cli_export（標準 CSV、JSONL 與 .run.json）以及 export_search_snapshot（遵守原文揭露授權的快照匯出）。

發布形式與生態系邊界

本 MCP 伺服器為本機 stdio 主控台程式與 Python 模組，並非 PyPI 公開套件、MCPB 封裝或官方 Model Context Protocol Registry 收錄項目。自動化測試以模擬測試驗證協定契約，不宣稱已通過各商用 AI 桌面端、macOS 或 Linux 環境的全面認證。

是否新增原文揭露授權由主機維運者審查實際文獻、版本與提供方條款後自行決定。傳回的所有古籍文本僅應視為研究資料，絕不可當作模型提示指令執行。
