連線的漢文（文言文）資料庫與本機文本匯入

Classic Pattern Explorer v3.3 連線分布於 5 個國家或地區的 19 個線上文獻來源，並支援對本機 UTF-8 資料夾及轉換文字集（.texts.jsonl）進行離線全文檢索。

註：Classic Pattern Explorer v3.3 支援 19 個線上資料來源，包含數位延喜式（官方瀏覽器檢索，CC BY 4.0）與東京大學 SHIPS 七庫選單。

本機文本資料夾與匯入工具

4 個獨立資料夾槽位（local–local4）中的 UTF-8 .txt、.md 與 .texts.jsonl 文字集均可完全離線全文檢索。

  • 韓國公共資料入口網站 XML/ZIP：支援匯入國史編纂委員會（三國史記、高麗史、朝鮮王朝實錄太祖~哲宗等）、韓國古典翻譯院、韓國學中央研究院藏書閣、東北亞歷史財團發布包及資料夾批次匯入。
  • Chinese Text Project（CTP/CText）：於 CTP 允許時可無金鑰嘗試取得單一章節；取得整部著作的章節目錄須自備個人 CTP API 金鑰。
  • 精選部分匯入與作品尋找：MPIWG 稀見地方志（每次預覽最多 50 個來源單元）、CBETA P5 XML、NDL OCR 頁面、古騰堡計畫電子書及作品尋找精靈。
  • 書目中繼資料（.manifest.toml）：於文本旁放置 NAME.txt.manifest.toml 可記錄 title、edition、era、year 與 year_end 以供年代排序。

檢索範圍與聲明邊界

Classic Pattern Explorer 為獨立個人專案（MIT 授權條款），與上述任何機構或資料庫均無隸屬關係，軟體不捆綁任何語料庫、現代譯文或 API 原始回應。

線上檢索僅在提供方限制內取得有限摘錄或書目參照，不執行全庫下載。檢索無結果並不代表該文獻中不存在對應句式。
