漢文句式檢索流程（以…爲、雖…而）與 FAQ

結合本機全文檢索與線上資料庫摘錄定位句式候選用例，檢視 A/B 欄位與結構線索，在不更動原文用字的前提下保存個人研讀筆記。

模式 DSL 視覺建構器、檢討筆記與候選比較與單項檢索、組合檢索一同包含於 v3.3 中。

三種檢索模式

1. 單項檢索

尋找詞語或片語。本機資料夾支援布林運算子 AND、OR、NOT、精確片語 "phrase" 與字距 NEAR/n；線上來源則依各自介面規則運作。

2. 組合檢索

輸入第一與第二要素（如 以 與 爲、雖 與 而）尋找依序共現句段，可用 ⇄ 互換順序，並檢視間隔欄 A 與後文欄 B。

3. 模式 DSL（本機）

v3.3 可在介面中直接組合詞框（支援 | 備選字）、字距上下限、排除字與句／分句／字窗邊界，或載入 UTF-8 .toml 模式檔案。

模式 DSL 寫法範例（.toml 與視覺建構器）

可在模式檔案中為 以…爲、雖…而、非…不 等構式設定槽位長度與邊界條件：

schema = 1

[[pattern]]
id = "yi-wei"
expr = "以 {A:1..20} 爲 {B:1..20} @sentence"

[[pattern]]
id = "sui-er"
expr = "雖 {A:1..20} 而 {B:1..20} @sentence"

[[pattern]]
id = "fei-bu"
expr = "非 {A:1..20} 不 {B:1..20} @sentence"
  • {A:1..20} 擷取 1 至 20 個字元存入命名槽位 A；需要時可用 {A:1..20 not 是} 排除特定字元。
  • {..3} 表示最多 3 字的非擷取間隔（在視覺建構器中留空或填 0 表示緊鄰比對）。
  • @sentence、@clause、@window:N 指定比對邊界；非單純二元對結構會歸入 待確認（classification_unreviewed）。

證據核驗與原文保護原則

原文用字保持不變

無論選擇何種介面語言，漢文、漢喃與吏讀原文始終原樣呈現；僅於正規化選項中明確設定時才啟用異體字對應。

檢討筆記與候選比較

可將本機或線上卡片中的用例存入檢討筆記，記錄審核狀態、筆記與來源欄位並並列比較。

截斷邊界省略號（…）

當線上摘錄於提供方字數邊界處截斷時，即使位於句號之後亦會附加 …，避免誤認為完整句段。

常見問題解答（FAQ）

為何部分線上資料庫回傳 0 筆結果或拒絕包含空白的檢索詞？

實錄、韓國史資料庫、NAHF、NRICH、ITH、SAT、AKS、THDL、CSID、CanD、奎章閣、SHIPS、數位延喜式等公開檢索入口僅接受不含空白、引號或運算子的連續詞語；NDL 則要求至少 2 個字元。無結果僅表示目前回傳片段未命中，不能證明全庫無此用例。

「可能性較高／較低」分組是否代表程式給出了語法判斷？

不是。組合檢索的分組（以及模式 DSL 中的「已比對」／「待確認」）僅依據是否跳過較近的第二要素或是否跨越分句標點等結構線索排序，不能替代研究者的原文研讀與語法判斷。

切換介面語言會改變原文的繁簡字體或異體字嗎？

不會。在繁體中文、簡體中文、韓語、日語、越南語與英語之間切換僅改變軟體介面文字，絕不改寫或轉換原文用字與標點。

本機資料夾中的 .docx 或 .pdf 檔案為何無法讀取？

本機資料庫僅掃描 UTF-8 純文字（.txt、.md）以及程式匯入產生的 .texts.jsonl 檔案。請先將 Word 或 PDF 文件另存為 UTF-8 純文字（.txt）。

能否匯出檢索結果與研讀記錄用於論文引用或分析？

可以。桌面端匯出功能（CSV/JSONL 及 .meta.json 來源中繼資料）、命令列（cpe match）及檢討筆記皆支援匯出目前結果與筆記。
