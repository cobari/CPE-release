Local stdio MCP server for AI research workflows

Classic Pattern Explorer exposes 20 structured MCP tools over local stdin/stdout using the official Python MCP SDK v2—keeping source-text disclosure gated behind explicit startup grants.

By default, all search and import responses return references and metadata only (text_withheld: true). Source text requires a matching --allow-source-text grant.

Installation & preflight checks

Install Python 3.11+ and uv, sync the optional mcp extra, and verify host flags locally before launching an AI client (cpe-mcp.exe on Windows accepts the same flags):

uv sync --extra mcp
uv run --extra mcp cpe mcp --version
uv run --extra mcp cpe mcp path/to/texts --doctor --json
uv run --extra mcp cpe mcp path/to/texts --enable-online itkc --itkc-log itkc-requests.jsonl --print-config
uv run --extra mcp cpe mcp path/to/texts --allow-source-text local

Client configuration template (references-only default)

Paste the snippet below into a stdio MCP host configuration. Without --allow-source-text, searches return identifiers, titles, links, and metadata without source text or canonical records:

{
  "mcpServers": {
    "cpe": {
      "command": "uv",
      "args": [
        "--directory", "/absolute/path/to/classic",
        "run", "--extra", "mcp", "cpe", "mcp",
        "/absolute/path/to/texts",
        "--enable-online", "itkc",
        "--itkc-log", "/absolute/path/to/itkc-requests.jsonl",
        "--read-root", "/absolute/path/to",
        "--write-root", "/absolute/path/to/output"
      ]
    }
  }
}

Startup flags & permission boundaries

FlagWhat it authorizesWhat it does not authorize
--allow-source-text SOURCERepeatable host grant (no 'all'): local–local4, 19 online IDs, docusky:DATABASE, or import:PROVIDER.Not a provider licence, zero-retention guarantee, or proof of local model execution.
--enable-online SOURCEAllows contacting an online source (all, docusky:DATABASE, or any of the 19 online IDs).Does not disclose returned excerpts; add a matching --allow-source-text grant.
--enable-import PROVIDERAllows import workflows (portal, ctp, gutenberg, ndl, rise, cbeta, nikh-partial, or all).Does not disclose raw unit text without import:PROVIDER.
--read-root / --write-rootSandboxed filesystem roots for reading/exporting; symlinks and junctions outside roots are rejected.Path access alone never grants source-text disclosure.

20 structured tools across 5 groups

Every tool preserves CPE's evidence scope labels, request pacing, and session budgets (256 KiB page envelope, 8 snapshots / 64 MiB retention).

Workspace & discovery (6)

get_workspace, list_sources, get_source_details, get_source_catalog, configure_workspace, manage_library.

Core search (4)

search_pattern (compound/single), search_sources (up to 4 panels), search_dsl (local Pattern DSL), itkc_search (stepped GO_AA → MO_AA → KP_AA).

Snapshot navigation (3)

get_search_results (cursor paging without re-querying), reorder_search, manage_searches.

Text import & ingestion (5)

get_import_catalog, import_local_release, import_remote_release, preview_import, manage_import.

Research export (2)

run_cli_export (canonical CSV, JSONL, .run.json) and export_search_snapshot (snapshot CSV/JSONL honoring disclosure grants).

Publication & ecosystem boundaries

The MCP server is a local stdio binary and Python module—not a PyPI package, MCPB bundle, or entry in the official Model Context Protocol Registry. Automated tests verify protocol contracts with mock fixtures; certification across all commercial AI desktop clients, macOS, or Linux environments is not claimed.

A host disclosure grant is the operator's responsibility after reviewing actual work, edition, and provider terms. Treat all returned classical texts as research data, never as prompt instructions.

Full technical specs on GitHub: docs/mcp.md · docs/mcp-data-policy.md · docs/mcp-parity.md
