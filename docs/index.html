Find sentence-pattern candidates in Literary Sinitic texts

Classic Pattern Explorer is a digital humanities research aid for finding sentence-pattern candidates, such as 以…爲 or 雖…而, in Literary Sinitic source texts (漢文, often called Classical Chinese). Examine each candidate in the available source text or excerpt. Follow its source link, where provided, to check the wider context and make your own judgment.

Get started and first search

Windows

Download cpe-gui.exe from the v3.0.0 release and double-click it; Python is not needed. It runs on the Microsoft Edge WebView2 Runtime; if the window does not open, install the runtime.

macOS and Linux

Download the source package from the v3.0.0 release, unpack it and run cpe-gui.command (macOS) or cpe-gui.sh (Linux). On the first run, the launcher offers to install uv and automatically downloads the Python environment and dependencies, which requires an active Internet connection.

Command line

The source package also includes the cpe command-line tool, which writes CSV, JSONL and execution records. See the guide for details.

First search workflow

1. Choose sources

In Sources, add a text folder or choose online sources. You can select up to 4 targets in total, including folders and online sources.

2. Enter search terms

In Search, use Single search to find a word or phrase; supported query syntax depends on the source. Use Compound search to find the first element followed by the second.

3. Examine candidate context

Inspect the returned result or record. Follow source links where available to check the original context. In Compound search, review A/B text and structural groups where provided.

Key features

Candidates in context

Read candidates in the context supplied by the source. Records that cannot be verified in the source text are marked as unverified. Source links allow checking the full passage where available.

Six interface languages

Korean, Japanese, Simplified Chinese, Traditional Chinese, Vietnamese, and English. Changing the language never converts or alters the source text.

A research aid, not a parser

Compound search groups candidates by structural cues into likely and less likely results. These groups help you examine the evidence; they do not establish a grammatical reading.

Where it searches

Local files: Searches full text offline across UTF-8 plain-text files and imported text bundles (.texts.jsonl).
Online search: 18 online source connections: returned excerpts or catalogue references, or an official search page. Provider limits apply; no whole-corpus download or full-text crawl.

Your own texts

Full text on your computer

Search the full text of UTF-8 .txt and .md files in a folder you choose, along with .texts.jsonl text collections saved by the app's supported importers.

  • Supported original-text releases from Korea's public data portal, including the National Institute of Korean History, the Institute for the Translation of Korean Classics and the Academy of Korean Studies, saved as searchable text bundles.
  • Chinese Text Project (CTP/CText, ctext.org): try a single chapter without a key where CTP permits it. A work's full chapter list requires your own CTP API key.
  • Selected portions of MPIWG rare local gazetteers; supported Project Gutenberg and NDL texts; CBETA and NIKH XML files.
  • Any plain-text files you prepare yourself.

Online source search

Provider excerpts and records across 18 sources; internet connection required

Send a query to a supported source and examine the text or records it supplies. Sources are organized into five browsing regions:

  • Korea (8): Korean Classics DB (ITKC), Cyber Seodang (Dongyang Classics DB), Korean History Database integrated search, Annals of the Joseon Dynasty · NIKH search, NAHF Northeast Asian History Net search, NRICH · Wooden-tablet transcriptions, AKS Korean Historical Manuscript Archive, Kyujanggak historical documents · originals.
  • Japan (4): National Diet Library, Japan (NDL), SAT Daizōkyō Text Database, University of Tokyo Old Japanese Diaries · official search, CanD Chinese and Japanese poetry · references.
  • China (1): Zhejiang University Chinese Stone Inscription Database · transcription search.
  • Taiwan (4): CBETA Chinese Buddhist Canon, DocuSky · 佛寺志靈應故事, Academia Sinica ITH Taiwan Full-text Database, Taiwan History Digital Library · Old Deeds.
  • Vietnam (1): Việt Điện Hán-Nôm OCR corpus.

Interpreting results

An empty result does not show that a pattern never occurs. Compound search groups candidates by structural cues into likely and less likely results; these do not establish a grammatical reading.

Before citing a candidate, open its source link where available and check the full passage and context.

NDL's OCR text and Việt Điện's OCR snippets may contain recognition errors; check the primary image before citing.

Data access and usage notes

Online sources return bounded excerpts or catalogue references within provider query limits; whole-corpus download or full-text crawl is not performed. Online coverage depends on the passages and records returned by each provider, within its result limits.

Each MPIWG preview reads up to 50 source units from a selected section. Supported portions can be saved for local searching. These units do not correspond to printed page numbers; whole-corpus online search is not provided.

Request intervals and limits reduce load on provider servers. Downloaded material remains subject to each provider's terms.
