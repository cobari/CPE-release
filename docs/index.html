Find sentence-pattern candidates in Literary Sinitic texts

Classic Pattern Explorer is a digital humanities research aid for finding sentence-pattern candidates, such as 以…爲 or 雖…而, in Literary Sinitic source texts (漢文, often called Classical Chinese). Each candidate is shown with the context its text or the source's excerpt provides, alongside a source link where available, so you can read and judge it yourself.

What it does

Candidates in context

Read candidates in the context supplied by the text or provider, with source links where available. Records that cannot be checked against the returned text are marked as unverified.

Five interface languages

Korean, Japanese, Simplified Chinese, Traditional Chinese and English. Changing the language never converts or alters the source text. (This website guide is provided in six languages, including Vietnamese.)

A research aid, not a parser

In compound search, candidates are grouped by structural cues into likely and less likely results. That grouping is not a grammatical verdict; the reading stays with you.

Where it searches

Your own texts

Full text on your computer

A folder you choose: UTF-8 .txt and .md files, and .texts.jsonl bundles the window writes for institute originals. The text of each file is searched in full.

  • Supported original-text releases from Korea's public data portal, including the National Institute of Korean History, the Institute for the Translation of Korean Classics and the Academy of Korean Studies, saved as searchable text bundles.
  • Chinese Text Project (CTP/CText, ctext.org): try a single chapter without a key where CTP permits it. A work's full chapter list requires your own CTP API key.
  • Selected portions of MPIWG rare local gazetteers; supported Project Gutenberg and NDL texts; CBETA and NIKH XML files.
  • Any plain-text files you prepare yourself.

Online source search

Returned passages and records; Internet needed

The app sends your search to a supported source and checks the text it returns.

  • Korean Classics DB (ITKC): original-text collections Classical Texts and Korean Literary Collections (~150-character excerpts). Translated collections such as the Annals of the Joseon Dynasty are not searched.
  • National Diet Library of Japan (NDL): OCR text of classical books; at least one search element must contain two or more characters.
  • CBETA Chinese Buddhist Canon: excerpts of about 40 characters on each side of a hit.
  • Cyber Seodang (Dongyang Classics DB): returned passages or record information with source links. Candidates that cannot be verified in the returned text are marked as unverified.
  • DocuSky: limited to selected stories from 普陀洛迦新志靈應故事 and 清涼山志靈應故事 in the 佛寺志靈應故事 database, not the complete books.

Limits to keep in mind

  • Online coverage depends on the passages and records returned by each provider, within its result limits.
  • An empty result does not show that a pattern never occurs.
  • NDL's OCR text may contain recognition errors; check the page image before citing.
  • MPIWG imports supported portions from up to 50 source units in a selected section at a time, for local searching. These units do not correspond to printed page numbers; whole-corpus online search is not provided.
  • Before citing a candidate, open its source where a link is available and check the full passage.
  • Request intervals and limits protect provider servers. Downloaded material remains subject to the provider's terms.

Get started

Windows

Download cpe-gui.exe from the v2.0 release and double-click it; Python is not needed. It runs on the Microsoft Edge WebView2 Runtime; if the window does not open, install the runtime.

macOS and Linux

Download the source package from the v2.0 release, unpack it and run cpe-gui.command (macOS) or cpe-gui.sh (Linux). On the first run it offers to install uv and downloads the Python environment, so it needs an Internet connection.

Command line

The source package also has the cpe command, which writes CSV, JSONL and run records. See the guide for details.
