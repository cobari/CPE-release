Find sentence-pattern candidates in Literary Sinitic texts

Classic Pattern Explorer is a digital humanities tool that looks for patterns such as 以…爲 or 雖…而 in Literary Sinitic source texts (漢文, often called Classical Chinese) and shows each candidate with the context its text or the source's excerpt provides, so that you read and judge it yourself.

What it does

  • Candidates in context

    Each result shows the passage where the pattern occurs, as far as the text or the source's excerpt goes, and, where the source gives one, a link back to it.

  • Five interface languages

    Korean, Japanese, Simplified Chinese, Traditional Chinese and English. Changing the language never converts or alters the source text.

  • A research aid, not a parser

    In compound search, candidates are sorted by structural cues into likely and less likely results. That grouping is not a grammatical verdict; the reading stays with you.

Where it searches

Your own texts

Full text on your computer

A folder you choose: UTF-8 .txt and .md files, and the .texts.jsonl bundles the window writes for institute originals. The text of each file is searched in full.

  • Originals the window downloads from Korea's public data portal and saves as .texts.jsonl bundles: releases of the National Institute of Korean History and the Institute for the Translation of Korean Classics.
  • Works imported chapter by chapter from the Chinese Text Project (CTP/CText, ctext.org) with your own API key, saved as .txt files.
  • Any plain-text files you prepare yourself.

Online excerpt search

Excerpts, Internet needed

The window sends your search to the source and matches the passages it returns.

  • Korean Classics DB (ITKC): the original-text collections Classical Texts and Korean Literary Collections, excerpts of about 150 characters. Its translated collections, such as the Annals of the Joseon Dynasty, are not searched.
  • National Diet Library of Japan (NDL): OCR text of classical books; at least one search element must be two or more characters long.
  • CBETA Chinese Buddhist Canon: excerpts of about 40 characters on each side of a hit.

Limits to keep in mind

  • Online results are the passages each source returns, often cut at both ends, from the first 50 to 100 records, books or juan per source or collection.
  • An empty result does not show that a pattern never occurs.
  • NDL's OCR text contains recognition errors; check the page image before citing.
  • Before citing any example, open its source and read the full passage.
  • To spare the sources' servers, the window sends at most 200 requests to each online source in a session.

Get started

Windows

Download cpe-gui.exe from the v1.0 release and double-click it; Python is not needed. It runs on the Microsoft Edge WebView2 Runtime; if the window does not open, install the runtime.

macOS and Linux

Download the source package from the v1.0 release, unpack it and run cpe-gui.command (macOS) or cpe-gui.sh (Linux). On the first run it offers to install uv and downloads the Python environment, so it needs an Internet connection.

Command line

The source package also has the cpe command, which writes CSV, JSONL and run records. See the guide for details.
