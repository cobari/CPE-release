한문 원문에서 문형 후보를 찾습니다

Classic Pattern Explorer는 한문(漢文, Literary Sinitic) 원문에서 以…爲, 雖…而 같은 문형을 찾는 디지털 인문학 도구입니다. 후보마다 그 텍스트나 자료원의 발췌문이 담은 문맥을 보여 주고, 읽고 판단하는 일은 연구자가 합니다.

Windows용 내려받기cpe-gui.exe, 64비트 v1.0 전체 내려받기 사용 안내 읽기

하는 일

  • 문맥 속의 후보

    결과마다 문형이 나오는 구절을 텍스트나 자료원의 발췌문이 담은 만큼 보여 주고, 출처에 링크가 있으면 그 링크도 붙입니다.

  • 다섯 가지 화면 언어

    한국어, 일본어, 중국어 간체·번체, 영어. 화면 언어를 바꿔도 원문은 변환되거나 바뀌지 않습니다.

  • 구문 분석기가 아닌 연구 보조 도구

    복합 검색에서는 후보를 구조적 단서에 따라 두 묶음으로 나눕니다. 이 구분은 문법 판정이 아니며, 판단은 연구자의 몫입니다.

검색 대상

내 텍스트

내 컴퓨터의 전체 텍스트

직접 고른 폴더의 UTF-8 .txt·.md 파일과, 기관 원문을 변환해 저장한 .texts.jsonl 묶음 파일. 각 파일의 텍스트 전체를 검색합니다.

  • 프로그램이 공공데이터포털에서 내려받아 .texts.jsonl 묶음으로 저장하는 기관 원문: 국사편찬위원회와 한국고전번역원 자료.
  • 본인 API 키로 Chinese Text Project(CTP/CText, ctext.org)에서 장 단위로 가져와 .txt로 저장한 작품.
  • 직접 준비한 일반 텍스트 파일.

온라인 발췌 검색

발췌문, 인터넷 필요

검색어를 자료원에 보내고, 돌아온 구절에서 문형을 맞춰 봅니다.

  • 한국고전종합DB(ITKC): 원문 컬렉션인 고전원문과 한국문집총간, 약 150자 발췌. 조선왕조실록 같은 번역 컬렉션은 검색하지 않습니다.
  • 일본 국립국회도서관(NDL): 고전 자료의 OCR 텍스트. 검색 요소 가운데 하나는 두 글자 이상이어야 합니다.
  • CBETA 전자불전: 검색어 앞뒤로 약 40자씩 발췌.

알아 둘 한계

  • 온라인 결과는 자료원이 돌려준 구절로 양끝이 잘린 경우가 많으며, 자료원·컬렉션마다 처음 50~100건(기록·책·권)까지만 봅니다.
  • 결과가 없다고 해서 그 문형이 쓰이지 않았다는 뜻은 아닙니다.
  • NDL의 OCR 텍스트에는 인식 오류가 있으니, 인용하기 전에 쪽 이미지를 확인하세요.
  • 용례를 인용하기 전에는 출처를 열어 전체 원문을 읽으세요.
  • 자료원 서버를 배려해, 한 세션에서 온라인 자료원마다 요청을 최대 200번까지만 보냅니다.

시작하기

Windows

v1.0 릴리스에서 cpe-gui.exe를 내려받아 두 번 클릭하면 됩니다. Python은 필요 없습니다. Microsoft Edge WebView2 런타임으로 실행되므로, 창이 열리지 않으면 런타임을 설치하세요.

macOS와 Linux

v1.0 릴리스에서 소스 패키지를 내려받아 압축을 풀고 cpe-gui.command(macOS)나 cpe-gui.sh(Linux)를 실행합니다. 처음 실행할 때 동의하면 uv를 설치하고 Python 환경을 내려받으므로 인터넷 연결이 필요합니다.

명령줄

소스 패키지에는 CSV, JSONL과 실행 기록을 저장하는 cpe 명령도 들어 있습니다. 자세한 내용은 사용 안내를 보세요.

버전 1.0(태그 v1.0). MIT 라이선스. 연결하는 기관이나 데이터베이스와 관계없는 개인 프로젝트입니다. 데이터베이스의 원문 묶음, 현대 번역, API 원응답은 들어 있지 않습니다.
