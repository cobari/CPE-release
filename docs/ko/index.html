한문 원문에서 문형 후보를 찾습니다

Classic Pattern Explorer는 한문(漢文, Literary Sinitic) 원문에서 以…爲, 雖…而 같은 문형을 찾는 디지털 인문학 연구 보조 도구입니다. 원문이나 제공된 발췌문에서 후보의 문맥을 살피고, 출처 링크가 있으면 전체 원문도 대조할 수 있습니다. 문형에 해당하는지는 연구자가 직접 읽고 판단합니다.

Windows용 내려받기cpe-gui.exe, 64비트
v3.1 다운로드 목록macOS·Linux 소스 패키지 사용 안내 읽기상세 설명서 (README)

Windows에서는 cpe-gui.exe를 내려받아 바로 실행하면 됩니다. Edge WebView2 런타임이 필요합니다. macOS와 Linux에서는 소스 패키지로 실행합니다. 처음 실행할 때 실행 환경을 자동으로 내려받으므로 인터넷 연결이 필요합니다. v3.1은 5개 지역으로 분류된 온라인 자료원 18개와 로컬 텍스트 폴더를 검색합니다.

시작하기 및 첫 검색

Windows

v3.1 릴리스에서 cpe-gui.exe를 내려받아 두 번 클릭하면 됩니다. Python은 필요 없습니다. Microsoft Edge WebView2 런타임으로 실행되므로, 창이 열리지 않으면 런타임을 설치하세요.

macOS와 Linux

v3.1 릴리스에서 소스 패키지를 내려받아 압축을 풀고 cpe-gui.command(macOS)나 cpe-gui.sh(Linux)를 실행합니다. 처음 실행할 때 uv 설치 동의를 묻고 Python 환경과 의존성을 자동으로 내려받으므로 인터넷 연결이 필요합니다.

명령줄

소스 패키지에는 CSV, JSONL과 실행 기록을 저장하는 cpe 명령줄 도구도 들어 있습니다. 자세한 내용은 사용 안내를 보세요.

첫 검색 절차

1. 자료원 선택

‘검색 소스’에서 텍스트 폴더를 추가하거나 온라인 자료원을 고르세요. 폴더와 온라인 자료원을 합쳐 최대 4개까지 선택할 수 있습니다.

2. 검색어 입력

‘검색’에서 단어나 구절을 찾으려면 단일 검색을 고르세요. 사용할 수 있는 검색식은 자료원마다 다릅니다. 첫째 요소 뒤에 둘째 요소가 나오는 곳을 찾으려면 복합 검색을 고르세요.

3. 문맥 대조 및 원문 확인

제공된 결과나 서지 정보를 살피고, 출처 링크가 있으면 원문 문맥을 대조하세요. 복합 검색에서는 A·B 원문과 구조적 단서에 따른 그룹이 제공되는 경우 함께 검토하세요.

주요 기능

문맥 속의 후보

제공된 문맥에서 후보를 확인합니다. 원문에서 확인할 수 없는 결과는 미확인으로 표시합니다. 출처 링크가 있으면 전체 원문도 대조할 수 있습니다.

6개 인터페이스 언어

한국어, 일본어, 중국어 간체, 중국어 번체, 베트남어, 영어. 화면 언어를 바꿔도 원문 표기는 절대 변환되거나 변경되지 않습니다.

구문 분석기가 아닌 연구 보조 도구

복합 검색은 구조적 단서를 바탕으로 가능성이 높은 후보와 낮은 후보를 나누어 보여 줍니다. 이 구분은 검토를 돕기 위한 것이며, 문법적 해석을 확정하지는 않습니다.

검색 대상

내 컴퓨터의 텍스트

내 컴퓨터의 전체 텍스트

직접 고른 폴더의 UTF-8 .txt·.md 파일과, 지원하는 가져오기 기능으로 저장한 .texts.jsonl 텍스트 묶음 파일의 본문 전체를 오프라인에서 검색합니다.

  • 공공데이터포털에서 지원하는 국사편찬위원회·한국고전번역원·한국학중앙연구원의 원문 자료를 내려받아 검색할 수 있는 텍스트 묶음으로 저장합니다.
  • Chinese Text Project(CTP/CText, ctext.org): 개별 장은 API 키 없이 가져오기를 시도할 수 있습니다. 작품 전체의 장 목록에는 본인의 CTP API 키가 필요하며, 실제 이용 가능 범위는 CTP가 정합니다.
  • MPIWG 희귀 지방지에서 고른 일부, 지원하는 프로젝트 구텐베르크·NDL 자료, CBETA·국사편찬위원회 XML 파일도 가져올 수 있습니다.
  • 직접 준비한 일반 텍스트 파일.

온라인 자료 검색

18개 자료원의 발췌문·서지 정보, 인터넷 연결 필요

자료원에 검색어를 보내고, 제공된 본문이나 자료 정보를 확인합니다. 일부 자료원은 그 대신 공식 검색 페이지를 엽니다. 제공처의 건수 제한이 적용됩니다. 5개 탐색 지역으로 분류되어 있습니다.

  • 한국(8): 한국고전종합DB (ITKC), 동양고전종합DB (사이버서당), 한국사데이터베이스 통합검색, 조선왕조실록 · 국사편찬위원회 검색, 동북아역사넷 검색, 국립문화유산연구원(NRICH) · 목간 판독문, 한국학중앙연구원 고문서자료관, 규장각 고문서 · 원문 검색.
  • 일본(4): 일본 국립국회도서관 (NDL), SAT 대정신수대장경 텍스트 데이터베이스, 도쿄대 고기록 전문DB · 공식 검색, CanD 중국·일본 한시 · 서지 참고.
  • 중국(1): 저장대 중국역대묘지DB · 녹문 검색.
  • 대만(4): CBETA 중화전자불전, DocuSky · 佛寺志靈應故事, 중앙연구원 대만사연구소 대만문헌전문데이터베이스, 대만역사디지털도서관 · 고계약문서.
  • 베트남(1): Việt Điện 한놈 OCR 말뭉치.

결과를 해석할 때 주의할 점

결과가 없다고 해서 그 문형이 쓰이지 않았다는 뜻은 아닙니다. 복합 검색의 후보 구분은 검토를 돕는 구조적 단서일 뿐이며, 문법적 해석을 확정하지는 않습니다.

용례를 인용하기 전에는 제공되는 출처 링크를 열어 전체 원문과 문맥을 확인하세요.

NDL 및 Việt Điển의 OCR 텍스트에는 인식 오류가 있을 수 있으니, 인용하기 전에 원본 이미지를 확인하세요.

자료 이용 안내

온라인 검색은 제공처의 건수 상한 내에서 제한된 발췌문이나 서지 정보만 가져오며, 대량 크롤링이나 전문 다운로드는 수행하지 않습니다. 온라인 검색에서 확인할 수 있는 범위는 자료원이 제공하는 발췌문과 자료 정보에 따라 달라지며, 결과 상한은 자료원마다 다릅니다.

MPIWG 지방지는 한 번의 미리보기에서 선택한 권차의 원본 단위를 최대 50개까지 읽습니다. 이 단위는 책의 쪽 번호와 다르며, 자료 전체의 온라인 검색은 지원하지 않습니다. 지원하는 부분만 내 컴퓨터에 저장해 검색할 수 있습니다.

자료원 서버의 부담을 줄이기 위해 요청 간격과 횟수를 제한합니다. 내려받은 자료에는 각 제공 기관의 이용 조건이 적용됩니다.

버전 3.1(태그 v3.1). MIT 라이선스. 연결하는 기관이나 데이터베이스와 관계없는 개인 프로젝트입니다. 데이터베이스의 원문 묶음, 현대 번역, API 원본 응답은 들어 있지 않습니다.
