AI 연구 워크플로우를 위한 로컬 stdio MCP 서버

공식 Python MCP SDK v2 기반으로 로컬 stdin/stdout에서 동작하는 20개 연구 도구를 제공하며, 원문 본문 노출은 호스트의 명시적 실행 인자로 엄격히 통제합니다.

기본 동작은 ‘참조 및 메타데이터 전용(text_withheld: true)’입니다. 로컬 파일이나 온라인 발췌 본문을 반환하려면 해당 자료원에 맞는 --allow-source-text 인자를 직접 지정해야 합니다.

설치 및 사전 점검 명령

Python 3.11 이상과 uv를 준비한 뒤 mcp 선택 의존성을 설치하고, 호스트 연결 전 로컬 점검 플래그로 설정을 확인하세요(Windows 독립 실행 파일 cpe-mcp.exe도 동일 인자 지원):

uv sync --extra mcp
uv run --extra mcp cpe mcp --version
uv run --extra mcp cpe mcp path/to/texts --doctor --json
uv run --extra mcp cpe mcp path/to/texts --enable-online itkc --itkc-log itkc-requests.jsonl --print-config
uv run --extra mcp cpe mcp path/to/texts --allow-source-text local

클라이언트 설정 예시 (기본 참조 전용)

아래 JSON을 stdio MCP 호스트 설정에 붙여 넣으세요. --allow-source-text가 없으면 식별자·제목·링크·메타데이터만 반환하며 원문 발췌문과 정규 레코드는 숨깁니다:

{
  "mcpServers": {
    "cpe": {
      "command": "uv",
      "args": [
        "--directory", "/absolute/path/to/classic",
        "run", "--extra", "mcp", "cpe", "mcp",
        "/absolute/path/to/texts",
        "--enable-online", "itkc",
        "--itkc-log", "/absolute/path/to/itkc-requests.jsonl",
        "--read-root", "/absolute/path/to",
        "--write-root", "/absolute/path/to/output"
      ]
    }
  }
}

실행 플래그와 권한 경계

실행 인자허용 범위허용하지 않는 것
--allow-source-text SOURCE반복 지정 가능한 원문 공개 허가(all 없음): local–local4, 19개 온라인 ID, docusky:DATABASE, import:PROVIDER.제공처 저작권 라이선스, 데이터 미보관 보증, 로컬 모델 실행 증명이 아닙니다.
--enable-online SOURCE온라인 자료원 접속 허용(all, docusky:DATABASE 또는 19개 온라인 ID).발췌 본문 공개까지 허용하지 않으므로 --allow-source-text가 별도로 필요합니다.
--enable-import PROVIDER가져오기 공급자 사용 및 미리보기·진행률 메타데이터 조회.import:PROVIDER 허가 없이는 단위 원문을 반환하지 않습니다.
--read-root / --write-root도구의 파일 읽기·쓰기 허용 루트(루트 밖 심볼릭 링크·정션 차단).경로 접근 권한만으로 원문 공개 권한이 부여되지는 않습니다.

5개 범주 · 20개 구조화 도구

모든 도구는 CPE의 증거 범위 표기, 요청 간격 보호, 세션 예산(응답 256 KiB 상한, 스냅샷 8개·64 MiB 유지)을 그대로 따릅니다.

작업공간·자료원 탐색 (6)

get_workspace, list_sources, get_source_details, get_source_catalog, configure_workspace, manage_library.

핵심 검색 (4)

search_pattern(복합/단일), search_sources(최대 4패널), search_dsl(로컬 패턴 DSL), itkc_search(GO_AA → MO_AA → KP_AA 단계 검색).

스냅샷 탐색·세션 (3)

get_search_results(재질의 없는 커서 페이지 이동), reorder_search, manage_searches.

원문 가져오기·변환 (5)

get_import_catalog, import_local_release, import_remote_release, preview_import, manage_import.

연구 데이터 내보내기 (2)

run_cli_export(정규 CSV·JSONL·.run.json) 및 export_search_snapshot(원문 공개 정책을 준수하는 스냅샷 내보내기).

배포 및 생태계 한계

로컬 MCP 서버는 로컬 stdio 콘솔 바이너리 및 Python 모듈이며 PyPI 패키지, MCPB 번들, 공식 MCP Registry 등록 항목이 아닙니다. 자동화 테스트는 모의 픽스처로 프로토콜 계약을 검증하며 모든 상용 AI 데스크톱 앱이나 macOS·Linux 환경에서의 공식 인증을 주장하지 않습니다.

원문 공개 인자 지정은 실제 저작물·판본·제공처 이용약관을 검토한 호스트 운영자의 결정입니다. 반환된 한문 원문은 언제나 연구 데이터로 취급해야 하며 모델에 대한 지시사항으로 해석해서는 안 됩니다.
