한문 문형 검색 방법(以…爲·雖…而) 및 FAQ

로컬 전문 검색과 온라인 발췌 검색을 결합해 문형 후보를 찾고, A·B 구간과 구조적 단서를 검토하며 원문 표기를 훼손하지 않고 연구 노트를 정리합니다.

패턴 DSL 시각 빌더, 검토 노트, 후보 비교 기능은 단일 검색·복합 검색과 함께 v3.3에 포함되어 있습니다.

세 가지 검색 모드

1. 단일 검색

단어나 구절을 찾습니다. 로컬 폴더에서는 AND, OR, NOT, 정확한 "구문", 글자 거리 NEAR/n을 지원하며, 온라인 자료원은 각 제공처의 입력 규칙을 따릅니다.

2. 복합 검색

첫째 요소와 둘째 요소(예: 以와 爲, 雖와 而)가 순서대로 나오는 문장을 찾습니다. ⇄ 버튼으로 순서를 바꾸고, 사이 구간 A와 뒤따르는 구간 B를 함께 살핍니다.

3. 패턴 DSL (로컬 전용)

v3.3에서는 단어 칸(| 선택지), 슬롯 최소·최대 글자 수, 제외 글자, 문장/절/범위 경계를 화면에서 조립하거나 UTF-8 .toml 패턴 파일을 불러와 다단계 문형을 정밀 검색할 수 있습니다.

패턴 DSL 작성 예시 (.toml 및 빌더)

以…爲, 雖…而, 非…不 같은 문형을 글자 간격과 경계 조건과 함께 정의할 수 있습니다:

schema = 1

[[pattern]]
id = "yi-wei"
expr = "以 {A:1..20} 爲 {B:1..20} @sentence"

[[pattern]]
id = "sui-er"
expr = "雖 {A:1..20} 而 {B:1..20} @sentence"

[[pattern]]
id = "fei-bu"
expr = "非 {A:1..20} 不 {B:1..20} @sentence"
  • {A:1..20}는 1~20자를 캡처해 A 슬롯에 담습니다. 필요 시 {A:1..20 not 是}처럼 제외 문자를 지정합니다.
  • {..3}는 캡처 없이 최대 3자 간격을 허용합니다(시각 빌더에서 비워 두거나 0이면 인접 일치).
  • @sentence, @clause, @window:N으로 검색 경계를 지정합니다. 단순 2요소 쌍이 아닌 패턴은 자동 분류 미검토(classification_unreviewed)로 구분해 보여 줍니다.

증거 확인과 원문 보존 원칙

원문 표기 불변

화면 언어를 무엇으로 선택하든 원문의 한자·한놈·이두는 그대로 유지됩니다. 이체자 매핑은 정규화 설정에서 직접 켠 경우에만 적용됩니다.

검토 노트와 후보 비교

로컬 또는 온라인 결과 카드의 후보를 ‘검토 노트’에 저장해 검토 상태와 연구 메모를 남기고 나란히 비교할 수 있습니다.

발췌 경계 표시(…)

온라인 자료원 발췌문이 제공처 절단 경계에 닿으면 구두점 뒤라도 말줄임표(…)를 붙여 온전한 문장으로 오해하지 않게 합니다.

자주 묻는 질문 (FAQ)

온라인 자료원 검색에서 결과가 0건이거나 공백을 입력할 수 없는 이유는 무엇인가요?

조선왕조실록(NIKH)·한국사DB·동북아역사넷·NRICH·ITH·SAT·AKS·THDL·CSID·CanD·규장각·SHIPS·연희식 등 다수의 공개 검색창은 공백·따옴표·연산자가 없는 연속된 단일 어구만 허용합니다. 또한 NDL은 2자 이상이 필요합니다. 결과가 없더라도 전체 문헌에 해당 용례가 없음을 뜻하지는 않습니다.

‘가능성 높음/낮음’ 분류가 문법적 정답을 판정해 주나요?

아닙니다. 복합 검색의 높음/낮음(패턴 DSL의 ‘일치’/‘검토 필요’)은 더 가까운 둘째 요소를 건너뛰었는지, 절 경계 구두점을 넘는지 같은 구조적 단서만 표시합니다. 실제 문법 해석과 인용 여부는 반드시 원문 링크를 열어 연구자가 직접 판단해야 합니다.

화면 언어를 바꾸면 한문 원문의 번체자·간체자·이체자가 바뀌나요?

바뀌지 않습니다. 한국어·일본어·중국어 간체·중국어 번체·베트남어·영어 전환은 UI 메뉴와 안내 문구만 바꾸며 원문 글자를 절대 변환하지 않습니다.

내 폴더에 넣은 .docx나 .pdf 파일이 읽히지 않는 이유는 무엇인가요?

로컬 텍스트 폴더는 UTF-8 일반 텍스트(.txt, .md)와 CPE 가져오기로 저장한 .texts.jsonl 파일만 읽습니다. 워드(.docx), 한글(HWP), PDF 파일은 해당 프로그램에서 UTF-8 .txt로 저장한 뒤 불러오세요.

검색 결과와 연구 메모를 파일로 내보낼 수 있나요?

네. GUI 상단의 내보내기(CSV/JSONL 및 .meta.json 출처 사이드카), CLI(cpe match), 검토 노트 JSONL 내보내기를 통해 확인한 결과와 연구 메모를 저장할 수 있습니다.
