연동 한문 원문 데이터베이스 및 로컬 자료 가져오기

Classic Pattern Explorer v3.3은 한국·일본·중국·대만·베트남 5개 지역 19개 온라인 자료원 검색과, 내 컴퓨터의 UTF-8 텍스트 폴더 및 변환 묶음(.texts.jsonl) 오프라인 전문 검색을 함께 지원합니다.

참고: Classic Pattern Explorer v3.3은 디지털 연희식(공식 브라우저 검색, CC BY 4.0)과 도쿄대 SHIPS 7개 DB 선택 기능을 포함해 19개 온라인 자료원을 연결합니다.

한국 (8개 온라인 자료원)

고전 원문·문집·사료·고문서·목간 판독문 검색을 지원합니다.

한국고전종합DB (ITKC)

고전원문(GO_AA) · 한국문집총간(MO_AA) · 한국고전총간(KP_AA)

각 서지 집합에서 최대 100건까지 검색하며 일치 어구 앞뒤 약 150자 발췌문과 출처 링크를 보여 줍니다. 번역문 집합(IT_AA)은 API 검색 대상에서 제외되며 자동 저장하지 않습니다.

동양고전종합DB (사이버서당)

최대 50건 · Open API

전통문화연구회 Open API로 제목, 설명, 원문 링크를 조회합니다. 전체 본문이나 원문·번역문 층위가 항상 구분·보장되지는 않으므로 후보 참고 자료로 확인하세요.

한국사데이터베이스 통합검색

첫 페이지 최대 20건 · 단일 어구

국사편찬위원회 통합검색에서 시대와 DB 항목을 선택해 공백·따옴표 없는 단일 검색어로 원문 탭 첫 페이지(최대 20건 발췌문과 /id/ 링크)를 조회합니다.

조선왕조실록 · 국사편찬위원회 검색

첫 페이지 최대 50건 · 단일 어구

실록 원문 탭 공개 검색창에 공백 없는 단일 검색어를 보내 첫 페이지 최대 50건의 발췌문과 기사 링크를 불러옵니다. 페이지 넘김이나 전체 크롤링은 하지 않습니다.

동북아역사넷 검색

21개 사료집 선택 · 첫 페이지 최대 20건

동북아역사재단 사료라이브러리에서 사료집 하나를 고른 뒤 단일 검색어로 원문 첫 페이지 최대 20건의 제목·발췌문·링크를 조회합니다.

국립문화유산연구원(NRICH) · 목간 판독문

세션당 최대 600건 · 단일 어구

공개 목간 판독문(한자·이두 및 판독 불확실 기호 유지)을 최대 600건까지 불러와 공백 없는 연속 문자열로 후보를 대조합니다.

한국학중앙연구원 고문서자료관

첫 페이지 최대 20건 · CC BY-NC-ND 2.0 KR

원문(anciTXT) 그룹 첫 페이지에서 최대 20건의 고문서 제목, 판독 발췌문, 날짜, UCI 링크를 조회합니다. 개인 비영리 연구용이며 재배포를 금합니다.

규장각 고문서 · 원문 검색

첫 20건 서지 · 인라인 발췌 최대 600자

서울대 규장각 GMS 고문서군에서 공백 없는 80자 이내 검색어로 첫 20건의 문서 번호, 당사자, 날짜, 원문 발췌와 공식 뷰어 링크를 확인합니다.

일본 (5개 온라인 자료원)

근현대·고전 OCR, 대장경 행 단위 검색, 고기록, 연희식, 한시 서지 목록을 지원합니다.

일본 국립국회도서관 (NDL)

OCR 발췌문 · 2자 이상 · 첫 50책

NDL Lab 고전적 OCR 본문을 검색합니다(최소 2자 이상 어구 필요). OCR 오인식이 있을 수 있고 구두점이 없으므로 인용 전 제목 링크로 원본 이미지를 확인하세요.

SAT 대정신수대장경 텍스트 데이터베이스

첫 30건 행 단위 · 단일 어구

도쿄대 SAT DB에서 첫 30건의 대정신수대장경 쪽·행 범위와 KWIC 발췌문을 불러옵니다. 이미지 전용 한자는 □로 표시하며, CBETA 대정장 본문과 겹치되 행 번호를 제공합니다.

도쿄대 SHIPS · 공식 검색

7개 DB 선택 · 공식 검색 링크 열기

고기록(w16), 대일본사료(w61), 고문서(w10), 나라유문(w08), 헤이안유문(w09), 가마쿠라유문(w11), 남북조유문(w29) 중 하나를 골라 공백 없는 검색어로 공식 검색 페이지를 엽니다. 앱이 결과를 수집하지는 않습니다.

디지털 연희식(국립역사민속박물관) · 공식 검색

v3.3 추가 · 공식 검색 링크 열기 · CC BY 4.0

공백 없는 검색어 하나로 제공처 공식 검색 페이지를 엽니다. 제공처 페이지가 브라우저에서 본문을 필터링하며 CPE가 행이나 건수를 수집하지는 않습니다.

CanD 중국·일본 한시 · 서지 참고

첫 20건 서지 제목 · 최대 10자

이체자 확장 OFF 상태로 10자 이내 검색어를 보내 첫 20건의 서지 제목·저자·판본 개요 링크만 표시합니다(시 본문·훈독은 폐기).

중국 (1개 온라인 자료원)

석각 묘지명 녹문 서지 색인 검색을 지원합니다.

저장대 중국역대묘지DB · 녹문 검색

기본 7개 컬렉션 · 첫 15건 서지

저장대 CSID 녹문 필드를 공백 없는 단일 검색어로 조회해 첫 15건의 제목, 시대, 유물 유형, 공식 기록 링크를 표시합니다. 원문 발췌문은 반환되지 않습니다.

대만 (4개 온라인 자료원)

전자불전, DocuSky 공공 DB, 대만사 문헌, 고계약문서를 지원합니다.

CBETA 중화전자불전

좌우 각 약 40자 · 첫 50권 · CC BY-NC-SA 4.0

CBData API로 검색어 앞뒤 약 40자 발췌문을 받아 나머지 조건을 대조합니다(협주 제외). CBETA Online 권별 원문으로 연결됩니다.

DocuSky · 佛寺志靈應故事 외 검토 프로필 29종

페이지당 50건 · 수동 최대 5쪽

공개 DB 중 한 번에 하나씩 검색합니다(佛寺志靈應故事·承政院日記·朝鮮王朝實錄·大明一統志 등 검토 완료 29종과 미검토 목록 구분 표시).

중앙연구원 대만사연구소 대만문헌전문데이터베이스

첫 페이지 최대 20건 · 단일 어구

대만문헌전문을 공백 없는 단일 검색어로 조회해 첫 페이지 최대 20건의 서지·발췌문·링크를 보여 줍니다.

대만역사디지털도서관 · 고계약문서

첫 10건 · 최대 600자

THDL 고계약문서(Old Deeds)에서 공백 없는 단일 검색어로 첫 10건의 발췌문과 공식 문서 링크를 확인합니다. 명·청 행정문서와 담신당안은 범위 밖입니다.

베트남 (1개 온라인 자료원)

베트남 한놈(漢喃) 고전 OCR 말뭉치를 검색합니다.

Việt Điện 한놈 OCR 말뭉치

첫 페이지 최대 20건 · 단일 어구

Digitizing Vietnam의 Việt Điện 공개 OCR 검색에서 최대 20건의 쪽별 발췌문과 이미지 뷰어 링크를 불러옵니다. 기계 OCR 오차와 이체자 매칭이 있으므로 원판 이미지를 확인하세요.

내 컴퓨터의 텍스트 및 로컬 가져오기

독립된 4개 폴더 슬롯(local–local4)에 담은 UTF-8 .txt·.md 파일과 .texts.jsonl 묶음은 인터넷 없이 전문 전체를 검색합니다.

  • 한국 공공데이터포털 원문 XML/ZIP: 국사편찬위원회(삼국사기·삼국유사·고려사·조선왕조실록 태조~철종·고려사절요·비변사등록·한국사료총서 등), 한국고전번역원(임하필기·신증동국여지승람 등), 한국학중앙연구원 장서각 등록, 동북아역사재단(15163258 15종 일괄·동문휘고) 및 폴더 일괄 가져오기.
  • Chinese Text Project (CTP/CText): 제공처가 허용하는 경우 API 키 없이 개별 장 시도가 가능하며, 작품 전체 장 목록에는 사용자 본인의 CTP API 키가 필요합니다.
  • 부분 가져오기 및 작품 찾기: MPIWG 희귀 지방지(미리보기당 최대 50개 원본 단위), CBETA P5 XML, NDL OCR 페이지, 프로젝트 구텐베르크 전자책, 작품명 기준 연결 DB 안내(작품 찾기).
  • 서지 메타데이터(.manifest.toml): NAME.txt.manifest.toml을 함께 두면 title·edition·era·year·year_end를 기록해 연대순 정렬에 활용할 수 있습니다.

이용 범위 및 출처 경계

Classic Pattern Explorer는 연결 기관·데이터베이스와 무관한 개인 프로젝트(MIT 라이선스)이며, 원문 DB·현대 번역·API 원본 응답을 포함해 배포하지 않습니다.

온라인 검색은 각 제공처의 요청 상한 내에서 반환된 발췌문과 서지 정보만 대조하며 전체 크롤링을 하지 않습니다. 검색 결과가 0건이어도 해당 코퍼스에 용례가 없다는 뜻은 아닙니다.
