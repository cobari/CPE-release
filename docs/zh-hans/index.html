在文言文原文中查找句式候选

Classic Pattern Explorer 是一款面向数字人文（Digital Humanities）研究的辅助工具，用于在文言文（汉文，Literary Sinitic）原文中查找 以…爲、雖…而 等句式候选用例。研究者可在所获原文或摘录中查看候选用例的前后文，并通过提供的出处链接进一步核对原始资料，自行判断句式是否成立。

下载 Windows 版cpe-gui.exe，64 位
v2.0 下载列表macOS 与 Linux 源码包 阅读使用说明详细说明书 (README)

当前公开发布的 v2.0 版本尚未包含越南语。

主要功能

上下文中的用例

在提供的上下文中查验候选用例。在原文中无法核对的结果标为未核实。若有出处链接，亦可核对完整原始资料。

六种界面语言

简体中文、繁体中文、韩语、日语、越南语与英语。切换界面语言绝不会转换或改动原文用字。

研究辅助工具而非语法分析器

“组合检索”依据结构线索将候选用例分组，便于比较可能性较高和较低的结果。这种分组不等于语法判定，仍须结合前后文研读。

检索范围

本地文本

本地计算机中的全文检索

检索所选文件夹中 UTF-8 .txt、.md 文件的全文，以及程序通过支持的导入功能保存的 .texts.jsonl 文本合集文件。

  • 从韩国公共数据门户下载国史编纂委员会、韩国古典翻译院、韩国学中央研究院的古籍资料，保存为可检索的文本合集文件。
  • Chinese Text Project（CTP/CText, ctext.org）：单个章节可在 CTP 允许的情况下无需密钥尝试获取；整部著作的章节列表需要自备 CTP API 密钥，实际可用范围由 CTP 决定。
  • MPIWG 稀见地方志中所选的部分章节、支持的古登堡计划及 NDL 资料、CBETA 与国史编纂委员会 XML 文件。
  • 自行准备的纯文本文件。

在线数据源检索

机构返回的文句与资料信息，需网络连接

向数据源发送检索词，核对返回的文本。

  • 韩国古典综合数据库（ITKC）：原文文献库（古典原文、韩国文集丛刊与日省录，摘录约150字）。不检索朝鲜王朝实录等翻译库。
  • 日本国立国会图书馆（NDL）：古籍 OCR 文本。至少一个检索要素须包含两个或更多字符。
  • CBETA 电子佛典：提供检索词前后各约40字的摘录。
  • 东洋古典综合数据库：提供文句或资料信息及出处链接。返回文本中未核实检索条件者标为未核实候选。
  • DocuSky：仅检索 佛寺志靈應故事 数据库中 普陀洛迦新志靈應故事 与 清涼山志靈應故事 的故事选段，并非全书。

解读检索结果时的注意事项

  • 检索无结果并不代表该句式未曾使用。
  • 引用用例前，请打开提供的出处链接确认完整原文与前后文。
  • NDL 的 OCR 文本可能存在识别误差，引用前请核对页面图像底本。

数据利用与使用条件

  • 在线检索受各数据源返回的文句和资料信息范围限制，且存在单次检索结果上限。
  • MPIWG 方志的每次预览最多读取所选卷目的50个源单元，可将支持的部分保存为本地可检索文本。这些单位并不对应纸质书籍的页码；不提供整部语料库的在线检索。
  • 为减轻数据源服务器负担，程序限制了请求间隔与频次。下载的资料受各机构使用条款约束。

快速开始

Windows

从 v2.0 发布页面下载 cpe-gui.exe 双击运行即可，无需安装 Python。基于 Microsoft Edge WebView2 运行时 运行；若窗口未打开请安装该运行时。

macOS 与 Linux

从 v2.0 发布页面下载源码包并解压，运行 cpe-gui.command (macOS) 或 cpe-gui.sh (Linux)。首次运行时经同意会安装 uv 并下载 Python 环境，因此需要网络连接。

命令行

源码包内还包含可输出 CSV、JSONL 及运行记录的 cpe 命令工具。详情请参阅 使用说明。
