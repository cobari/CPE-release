在文言文原文中查找句式候选

Classic Pattern Explorer 是一款面向数字人文（Digital Humanities）研究的辅助工具，用于在文言文（汉文，Literary Sinitic）原文中查找 以…爲、雖…而 等句式候选用例。研究者可在所获原文或摘录中查看候选用例的前后文，并通过提供的出处链接进一步核对原始资料，自行判断句式是否成立。

程序运行界面示例

快速入门与首次检索

Windows

从 v3.0.0 发布页面下载 cpe-gui.exe 双击运行即可，无需预装 Python。基于 Microsoft Edge WebView2 运行时 运行；若窗口未能打开，请安装该运行时。

macOS 与 Linux

从 v3.0.0 发布页面下载源码包并解压，运行 cpe-gui.command（macOS）或 cpe-gui.sh（Linux）。首次运行时启动脚本会提示安装 uv 并自动下载 Python 环境及依赖，因此需要保持互联网连接。

命令行

源码包中还包含输出 CSV、JSONL 与运行记录的 cpe 命令行工具。详情请参阅 使用说明。

首次检索步骤

1. 选择检索来源

在“检索来源”中添加文本文件夹，或选择在线来源。文件夹与在线来源合计最多选择 4 个。

2. 输入检索词

在“检索”中选择单项检索，可查找词语或短语；支持的检索语法依来源而异。选择组合检索，可查找第一要素之后出现第二要素的位置。

3. 对照语境与查对原文

查看返回的结果或书目信息；如有来源链接，请打开核对原文上下文。组合检索如提供 A、B 栏的原文和结构线索分组，请一并考察。

主要功能

上下文中的用例

在提供的上下文中查验候选用例。在原文中无法核对的结果标为未核实。若有出处链接，亦可核对完整原始资料。

六种界面语言

简体中文、繁体中文、韩语、日语、越南语与英语。切换界面语言绝不会转换或改动原文用字。

研究辅助工具而非语法分析器

“组合检索”依据结构线索将候选用例分组，便于比较可能性较高和较低的结果。这种分组不等于语法判定，仍须结合前后文研读。

检索范围

本地文件：离线直接检索指定文件夹中的 UTF-8 文本文件及已导入的文本集（.texts.jsonl）全文。
在线资料检索： 连接 18 个在线来源，依来源提供摘录、书目信息或打开官方检索页面。遵守提供方的结果数量限制，不下载整个资料库或抓取全文。

本地文本

本地计算机中的全文检索

检索所选文件夹中 UTF-8 .txt、.md 文件的全文，以及程序通过支持的导入功能保存的 .texts.jsonl 文本合集文件。

  • 从韩国公共数据门户下载国史编纂委员会、韩国古典翻译院、韩国学中央研究院的古籍资料，保存为可检索的文本合集文件。
  • Chinese Text Project（CTP/CText, ctext.org）：单个章节可在 CTP 允许的情况下无需密钥尝试获取；整部著作的章节列表需要自备 CTP API 密钥，实际可用范围由 CTP 决定。
  • MPIWG 稀见地方志中所选的部分章节、支持的古登堡计划及 NDL 资料、CBETA 与国史编纂委员会 XML 文件。
  • 自行准备的纯文本文件。

在线数据源检索

18个资料源的摘录与书目记录，需要网络连接

向支持的在线来源发送检索词，查阅返回的文句或书目信息。按5个国家与地区分类：

  • 韩国（8）： 韩国古典综合数据库 (ITKC)、东洋古典综合数据库 (Cyber Seodang)、韩国史数据库综合检索、朝鮮王朝實錄，国史编纂委员会检索、东北亚历史财团 东北亚历史网检索、NRICH 木简释文（韩国）、韩国学中央研究院 古文书资料馆、奎章阁古文书 · 原文检索。
  • 日本（4）： 日本国立国会图书馆 (NDL)、SAT 大正新脩大藏經 · 文本数据库、东京大学古记录全文DB · 官方检索、CanD 中国与日本汉诗 · 书目参考。
  • 中国（1）： 浙江大学中国历代墓志数据库 · 录文检索。
  • 台湾（4）： CBETA 汉文佛典、DocuSky · 佛寺志靈應故事、中央研究院臺灣史研究所 臺灣文獻全文資料庫、THDL · 臺灣歷史數位圖書館古契書。
  • 越南（1）： Việt Điện 汉喃OCR语料库。

解读检索结果与利用须知

解读检索结果时的注意事项

  • 检索无结果并不代表该句式未曾使用。
  • “组合检索”的分组依据结构线索，旨在辅助研读，并不代表语法结论。
  • 引用用例前，请打开提供的出处链接确认完整原文与前后文。
  • NDL 与 Việt Điển 的 OCR 文本可能存在识别误差，引用前请核对原始图像。

数据利用与使用条件

  • 在线检索仅在提供方返回限制内获取有限摘录或书目记录，不执行全库下载或整篇爬取。
  • 在线检索受各数据源返回的文句和资料信息范围限制，且存在单次检索结果上限。
  • MPIWG 方志的每次预览最多读取所选卷目的50个源单元，可将支持的部分保存为本地可检索文本。这些单位并不对应纸质书籍的页码；不提供整部语料库的在线检索。
  • 为减轻数据源服务器负担，程序限制了请求间隔与频次。下载的资料受各机构使用条款约束。
