在文言文原文中查找句式候选

Classic Pattern Explorer 是一款面向数字人文（Digital Humanities）研究的辅助工具，用于在文言文（汉文，Literary Sinitic）原文中查找 以…爲、雖…而 等句式候选用例。每个用例均显示文本或数据源摘录所包含的上下文，并在可用时附带出处链接，供研究者亲自阅读和研判。

下载 Windows 版cpe-gui.exe，64 位 v2.0 全部下载 阅读使用说明

主要功能

  • 上下文中的候选

    在提供的正文或摘录范围内展示候选用例的上下文。无法在返回文本中确认的资料会标为未确认候选；有出处链接时一并提供。

  • 五种界面语言

    支持韩语、日语、简体中文、繁体中文和英语。切换界面语言绝不会转换或更改文献原文。

  • 研究辅助工具而非句法分析器

    在组合检索中，程序依据结构线索将候选用例分为两组呈现。这种分组并非语法判定，最终理解仍由研究者掌握。

检索范围

自己的文本

本机全文字符检索

检索所选文件夹中的 UTF-8 .txt、.md 文本，以及转换保存的机构原文 .texts.jsonl 合集文件。检索覆盖各文件的全部文本内容。

  • 支持从韩国公共数据门户获取国史编纂委员会、韩国古典翻译院及韩国学中央研究院的指定原文资料，并保存为可检索的文本集合。
  • 中国哲学书电子化计划（CTP/CText，ctext.org）：对于CTP允许的单个章节，可以尝试免密钥获取；整部作品的章节列表需要您自己的CTP API密钥。
  • 也可导入MPIWG稀见地方志的选定部分、支持的古腾堡计划及NDL资料，以及CBETA和国史编纂委员会的XML文件。
  • 研究者自行整理的各类纯文本文件。

在线资料检索

返回的文段与资料信息，需联网

将检索词发送至支持的数据源，再核对返回的文本。

  • 韩国古典综合DB（ITKC）：古典原文与韩国文集丛刊（约150字摘录）。不检索朝鲜王朝实录等现代翻译集合。
  • 日本国立国会图书馆（NDL）：古籍OCR文本；至少一个检索要素须为两个或更多字符。
  • CBETA 中华电子佛典协会：从大藏经原文中提取检索词前后约40字的用例摘录。
  • 东洋古典综合DB：展示返回的文段、资料信息及出处链接。无法在返回文本中核实检索条件的资料会标为未确认候选。
  • DocuSky：仅检索佛寺志靈應故事中的普陀洛迦新志靈應故事与清涼山志靈應故事两项资料。

需注意的使用局限

  • 在线检索限于各数据源返回的文段与资料信息；结果数量上限因数据源而异。
  • 没有结果并不能证明该句式从未出现。
  • NDL的OCR文本可能含有识别错误，引用前请核对书页图像。
  • MPIWG每次从选定章节的最多50个内容单元中导入支持的部分，供本地检索。这些单元并非印刷书页编号，也不提供整库在线检索。
  • 引用用例前，如有出处链接，请打开并核对完整原文与上下文。
  • 为减轻提供方服务器负担，程序设有请求间隔及次数上限。下载资料须遵守各提供方的使用条件。

开始使用

Windows

从 v2.0 发行版下载 cpe-gui.exe 并双击即可运行，无需 Python。Microsoft Edge WebView2 运行时为运行基础；若窗口未打开，请安装该运行时。

macOS 与 Linux

从 v2.0 发行版下载源码包，解压后运行 cpe-gui.command（macOS）或 cpe-gui.sh（Linux）。初次运行时若同意则会自动安装 uv 并下载 Python 环境，需要网络连接。

命令行

源码包中还包含可输出 CSV、JSONL 及运行记录的 cpe 命令。详情请参阅使用说明。
