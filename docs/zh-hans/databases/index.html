连接的汉文（文言文）数据库与本地文本导入

Classic Pattern Explorer v3.3 连接分布于 5 个国家或地区的 19 个在线文献来源，并支持对本机 UTF-8 文件夹及转换文本合集（.texts.jsonl）进行离线全文检索。

注：Classic Pattern Explorer v3.3 支持 19 个在线资料来源，包含数字延喜式（官方浏览器检索，CC BY 4.0）与东京大学 SHIPS 七库选择器。

汉文佛典、DocuSky 公开库、台湾文献全文与古契书检索。

本机文本文件夹与导入工具

4 个独立文件夹槽位（local–local4）中的 UTF-8 .txt、.md 及 .texts.jsonl 合集均可完全离线全文检索。

  • 韩国公共数据门户 XML/ZIP：支持导入国史编纂委员会（三国史记、高丽史、朝鲜王朝实录太祖~哲宗等）、韩国古典翻译院、韩国学中央研究院藏书阁、东北亚历史财团发布包及文件夹批量导入。
  • Chinese Text Project（CTP/CText）：在 CTP 允许时可无密钥尝试获取单章；获取整部书的章节目录需使用个人 CTP API 密钥。
  • 精选部分导入与作品查找：MPIWG 稀见地方志（每次预览最多 50 个来源单元）、CBETA P5 XML、NDL OCR 页面、古登堡计划电子书及作品查找向导。
  • 书目元数据（.manifest.toml）：在文本旁放置 NAME.txt.manifest.toml 可记录 title、edition、era、year 与 year_end 用于年代排序。

检索范围与声明边界
