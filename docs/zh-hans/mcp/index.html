面向 AI 研究工作流的本地 stdio MCP 服务器

基于官方 Python MCP SDK v2，通过本地 stdin/stdout 暴露 20 个研究工具，并将原文文本返回严格限定在宿主显式启动授权之内。

默认模式仅返回引用与元数据（text_withheld: true）。如需返回本地文本或在线摘录，必须在启动参数中为对应来源显式添加 --allow-source-text。

安装与启动前自检

安装 Python 3.11+ 与 uv 并同步 mcp 可选依赖后，可在连接客户端前先用自检参数验证本地配置（Windows 独立程序 cpe-mcp.exe 支持相同参数）：

uv sync --extra mcp
uv run --extra mcp cpe mcp --version
uv run --extra mcp cpe mcp path/to/texts --doctor --json
uv run --extra mcp cpe mcp path/to/texts --enable-online itkc --itkc-log itkc-requests.jsonl --print-config
uv run --extra mcp cpe mcp path/to/texts --allow-source-text local

客户端配置模板（默认仅返回引用）

将以下 JSON 填入支持 stdio 的 MCP 宿主配置。未配置 --allow-source-text 时，工具仅返回标识符、题名、链接与元数据，不返回正文与规范记录：

{
  "mcpServers": {
    "cpe": {
      "command": "uv",
      "args": [
        "--directory", "/absolute/path/to/classic",
        "run", "--extra", "mcp", "cpe", "mcp",
        "/absolute/path/to/texts",
        "--enable-online", "itkc",
        "--itkc-log", "/absolute/path/to/itkc-requests.jsonl",
        "--read-root", "/absolute/path/to",
        "--write-root", "/absolute/path/to/output"
      ]
    }
  }
}

启动参数与权限边界

启动参数授予的能力未授予的范围
--allow-source-text SOURCE可重复传入（无 all 值）：local–local4、19 个在线 ID、docusky:DATABASE、import:PROVIDER。不构成出版方版权许可、零留存承诺或本地模型运行证明。
--enable-online SOURCE允许请求指定在线来源（all、docusky:DATABASE 或 19 个在线 ID）。不包含返回原文摘录的权限，仍需配对 --allow-source-text。
--enable-import PROVIDER允许调用导入提供方并查看预览与进度元数据。未授予 import:PROVIDER 时不返回原始单元文本。
--read-root / --write-root限定工具可读写的文件系统根目录（拒绝越界符号链接与目录联接）。路径读写权不等于原文文本披露授权。

5 大类共 20 个结构化工具

所有工具均遵循 CPE 的证据范围标注、请求频次保护与会话预算（单页 256 KiB 上限，最多保留 8 个快照 / 64 MiB）。

工作区与来源发现（6）

get_workspace、list_sources、get_source_details、get_source_catalog、configure_workspace、manage_library。

核心检索（4）

search_pattern（组合/单项）、search_sources（最多 4 面板）、search_dsl（本地模式 DSL）、itkc_search（GO_AA → MO_AA → KP_AA 分步会话）。

快照浏览与管理（3）

get_search_results（基于游标翻页而不重复请求源站）、reorder_search、manage_searches。

文本导入与摄取（5）

get_import_catalog、import_local_release、import_remote_release、preview_import、manage_import。

研究数据导出（2）

run_cli_export（规范 CSV、JSONL 与 .run.json）以及 export_search_snapshot（遵守原文披露授权的快照导出）。

发布形式与生态边界

本 MCP 服务器为本地 stdio 控制台程序与 Python 模块，并非 PyPI 公开包、MCPB 捆绑包或官方 Model Context Protocol Registry 收录条目。自动化测试基于模拟桩验证协议契约，不宣称已通过各类商业 AI 桌面端、macOS 或 Linux 环境的全面认证。

是否添加原文披露授权由宿主运维者在审查具体文献、版本与提供方条款后自行决定。返回的所有古籍文本仅应视为研究数据，绝不能当作模型提示指令执行。
