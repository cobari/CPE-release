# Classic Pattern Explorer 3.0.0

[English](README.md) | [한국어](README.ko.md) | [日本語](README.ja.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [Tiếng Việt](README.vi.md)

Classic Pattern Explorer 是一款桌面程式兼命令列工具，用於在文言文（漢文，Literary Sinitic）原文中查找「以…爲」「雖…而」等句式的候選用例。每個候選都會連同該文本或資料來源摘錄所含的前後文一併顯示（出處有連結時也附上連結），供研究者親自閱讀與判斷。介面支援韓語、日語、簡體中文、繁體中文、越南語與英語；切換介面語言不會轉換或改動原文。

它不是語法判定器或句法分析器，而是面向數位人文研究的輔助工具：只負責收集候選，並在組合檢索中依結構線索分為「較可能符合的結果」與「較不可能符合的結果」，閱讀與判斷仍由研究者完成。

## 可以檢索什麼

3.0.0版本支援本機文字資料夾，並依5個國家與地區提供18個線上資料來源。線上資料來源依提供者的數量上限傳回有限的摘錄或書目紀錄。

| | 文本所在 | 結果 |
|---|---|---|
| **自己的文本** | 本機資料夾：UTF-8 `.txt`、`.md` 檔案，用本人 API 金鑰從中國哲學書電子化計劃（Chinese Text Project，CTP/CText，ctext.org）匯入的作品（儲存為 `.txt`），以及程式轉換從韓國公共資料入口網下載的機構原文（國史編纂委員會、韓國古典翻譯院、韓國學中央研究院等）後儲存的 `.texts.jsonl` 合集檔案 | 檢索每個檔案的全部文字；檢索範圍以檔案內容為限 |
| **線上摘錄與書目檢索** | 5個地區的18個線上資料來源（韓國 8、日本 4、中國 1、臺灣 4、越南 1）；需要連網 | 資料來源傳回的命中處前後段落或書目紀錄（常在兩端截斷），受各資料來源檢索上限約束 |

線上結果是資料來源傳回的段落或紀錄，受各資料來源上限限制，因此沒有結果並不能證明該句式從未出現。引用用例前，請開啟出處連結核對完整原文。

## 快速入門

### Windows（執行檔）

1. 造訪 [v3.0.0 發布頁面](https://github.com/cobari/CPE-release/releases/tag/v3.0.0) 並下載 Windows x64 專用執行檔 [cpe-gui.exe](https://github.com/cobari/CPE-release/releases/download/v3.0.0/cpe-gui.exe)。
2. 按兩下 `cpe-gui.exe` 即可開啟檢索視窗，不需安裝 Python 或 uv。
3. Windows 執行檔依賴 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/)。若無法啟動，請透過連結安裝 WebView2 執行階段。

> **注意**：單獨下載的 `cpe-gui.exe` 僅包含圖形檢索視窗，不包含命令列工具及模式定義檔案。若需使用命令列（CLI）功能，請使用下方的完整發行套件（原始碼）。

### macOS 與 Linux（發行套件啟動腳本）

Windows 執行檔無法在 macOS 或 Linux 上直接執行。請使用完整發行套件：

1. 從 [v3.0.0 發布頁面](https://github.com/cobari/CPE-release/releases/tag/v3.0.0) 下載原始碼壓縮檔（`Source code .zip` 或 `.tar.gz`）並解壓縮。
2. 保持解壓縮後的完整資料夾結構，執行對應的啟動腳本：
   - **macOS**：按兩下 `cpe-gui.command`。（將在終端機視窗中啟動。首次執行若彈出安全提示，請按一下滑鼠右鍵並選擇「開啟」。）
   - **Linux**：執行 `cpe-gui.sh`。（在檔案管理器中選擇「執行」或在終端機中執行。）
   - 若在檔案管理器中無法啟動，可在解壓縮後的資料夾中開啟終端機並執行 `sh cpe-gui.sh`。
3. 若系統尚未安裝 `uv`，啟動腳本會詢問是否使用官方安裝程式自動安裝（輸入 `y` 確認）。
4. 首次執行會自動下載所需的 Python 環境與執行階段相依套件（需要連網）。

## 首次檢索體驗（線上文獻來源）

1. 在**檢索來源**勾選要檢索的資料夾或線上資料來源，合計最多四項。
2. 按上方的書本圖示與程式名稱，返回檢索畫面。
3. 輸入檢索詞後按檢索。線上資料來源需要網路連線；結果只涵蓋資料來源回傳的範圍。

## 資料準備（我的文字檔案資料夾）

- 在**檢索來源**加入存有UTF-8 `.txt`、`.md`或已匯入`.texts.jsonl`的資料夾。可分別登記四個資料夾；移除登記不會刪除檔案。

- 開啟**匯入**，選擇新原文的儲存資料夾，再按**匯入原文資料**。儲存位置和檢索對象分別選擇；尚未指定時可在儲存時選擇資料夾。

- 選擇機構公開資料、CTP、Project Gutenberg、NDL、CBETA或韓國國史編纂委員會XML、MPIWG地方志。網址輸入處附有原網站連結。CTP單章可嘗試免金鑰存取，但整部作品的章目需要自己的CTP金鑰，能否存取由CTP決定。

- 對支援預覽的資料，按**預覽**檢查內容，選擇保留部分、填寫版本並勾選確認項。線上資料使用**下載**，電腦上已有的檔案使用**匯入**。不支援的內容會註明原因並排除。捲動正文時上方的關閉×會保留。

## 檢索方法與注意事項

### 檢索方式

- **組合檢索（預設）**：在句子中先出現第一要素，再出現第二要素，兩者之間可以有文字。點擊 ⇄ 可交換兩要素的位置。
- **單項檢索**：尋找包含特定詞語的句子。支援組合布林運算 `AND`、`OR`、`NOT`、精確片語 `"..."` 及字元間距限制 `NEAR/n`。

  - **Việt Điện 漢喃OCR語料庫**: 在Digitizing Vietnam漢喃語料庫Việt Điện的公開OCR檢索中，每次檢索一個詞或片語。只讀取第一頁最多20個資料頁結果，每筆結果顯示OCR摘錄，並連結至Việt Điện的頁面閱讀器。OCR由機器產生，未經校正，提供方還會比對異體字及簡繁體。因此，只有摘錄包含原樣輸入的文字時，才能核實該比對；其餘結果僅為候選參考。頁碼和資料詮釋資料可能缺漏或不一致。圖像及紀錄的權利與OCR的研究使用聲明分開規定。不儲存資料。

## 檢索結果解讀

每個相符項目以卡片形式展示，並在原文或摘錄包含的範圍內顯示目標句及其前後文。

- **組合檢索結果槽位**：
  - **A 槽**：第一要素與第二要素之間的夾詞部分。
  - **B 槽**：第二要素之後的候選用詞範圍（程式不會機械斷定唯一邊界，可能會列出若干候選切分）。
- **較可能符合的結果 vs 較不可能符合的結果**：
  - 在組合檢索中，程式根據形態特徵自動分組（如兩要素緊鄰無 A 槽、存在更近的第二要素、A 槽跨越了分句標點等）。在單項檢索中，所有相符結果均展示在單一的 **檢索結果** 分組中。
  - **此分類並非語法正誤判定。** 被歸入「較不可能符合」的結果中可能依然包含極有價值的特殊文言語法現象，必須由研究者親自研讀考證。
- **說明**：圖形檢索視窗中沒有將結果匯出為 CSV 檔案的按鈕。若學術研究需要表格格式的資料，請使用下方的命令列（CLI）工具。

## 高級進階：原始碼執行、詮釋資料與命令列 (CLI)

熟悉終端機操作的學者或開發者可在完整發行套件目錄下使用 `uv` 執行。手動安裝指南請參閱 [官方 uv 安裝文件](https://docs.astral.sh/uv/getting-started/installation/)。

### 從原始碼執行 GUI

```bash
uv sync --locked
uv run --locked cpe gui
# 或直接指定文字資料夾 (請將 path/to/texts 替換為實際路徑)：
uv run --locked cpe gui path/to/texts
```

### 文獻詮釋資料附屬檔案（可選）

在文字檔案旁放置設定檔可指定詳細文獻資訊（例如原文檔名若為 `my-text.txt`，則在實際檔名後附加 `.manifest.toml` 命名為 `my-text.txt.manifest.toml`）。支援的可選欄位包括 `title`、`edition`、`era`、`year` 與 `year_end`。若不提供此檔案，程式預設以檔名作為篇名，缺失年代資訊不會影響檢索。

### 命令列檢索 (CLI)

命令列檢索支援匯出 CSV、JSONL 及執行中繼資料。請將 `my-text.txt` 替換為實際檔案路徑：

```bash
# 查看說明
uv run --locked cpe --help

# 指定模式定義檔案和單個 UTF-8 文字檔案執行句式比對
# (--out results 是產生 results.csv、results.jsonl 和 results.run.json 的輸出前綴)
uv run --locked cpe match patterns/mvp.toml my-text.txt --out results

# 韓國古典綜合資料庫命令列工具
uv run --locked python itkc_search.py --help
```

## 常見問題 (FAQ)

**Q1. 文字檔案無法開啟或無法讀取。**

A. 本程式僅讀取 UTF-8 編碼的純文字檔案（`.txt`、`.md`）。直接將 Word（`.docx`）、HWP 或 PDF 的副檔名改為 `.txt` 無法轉換為純文字，請在相應軟體中重新另存為 UTF-8 文字檔案。

**Q2. 檢索結果沒有任何顯示。**

A. 請在**檢索來源**確認已勾選所需資料，且資料夾已載入。NDL至少需要一個兩字以上的檢索元素。可簡化檢索詞再試；無結果不代表歷史上不存在該用例。

**Q3. 線上搜尋時提示錯誤。**

A. 請檢查網路與資料來源的錯誤提示。每次執行的請求上限是本程式為保護資料來源設定的限制。複雜線上檢索式也受可向該資料來源傳送的必要檢索詞限制。亦可下載允許使用的原文，在本機檢索。

**Q4. 在 Windows 上執行檔 (cpe-gui.exe) 無法啟動。**

A. 發布的 `cpe-gui.exe` 適用於 64 位元 Windows (x64)。若按兩下無反應或報錯，請確認系統是否已安裝 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/) 並進行安裝。
